# Affiliate市场需求文档（MRD）

版本：v1.1  
日期：2026-10-23

> v1.1说明：基于v1.0同步2026-10-23用户确认的Q-007两项口径变更——佣金结算改为日结且不设最低提现限制；Hold改为动态机制（初始1天、按账户风险分递增，超过30天转冻结并进入人工审核）。其余待评审数值不因本版自动生效。

## 1. 决策摘要

### 1.1 项目要解决的问题

1. **客户覆盖度**：我方目前只有IB服务型返佣管道，缺少CPA一次性买断管道，投放买量、内容引流等渠道的客户覆盖不到，净新增获客受限。
2. **合作者倾向**：只有流量、不做客户服务的合作方（媒体、博主、买量方）倾向CPA一次性结算，我方没有CPA计划，等于对这类合作方关闭入口——Pepperstone、IC Markets均按此区分两类合作方（E-203、E-606）。
3. **填补风险控制**：IB属服务型持续返佣、佣金与客户后续交易绑定、风险天然自限，系统因此未建严格风控；CPA一次性买断、套利动机强，现有风控规则不覆盖，本次CPA系统建设将同步补齐这块空白——竞品均设反套利规则（E-101/102、E-602、E-218）。

## 2. 背景、现状与机会

### 2.1 现有业务基线

- 已有成熟IB体系，本项目在成熟IB基础上评估新增CPA业务的增量价值（CFD-D-006）；

- 现有IB计佣细则、可复用系统能力清单待核实（Q-005）。

## 3. 项目目标与成功标准

### 3.1 北极星指标

**有效FTD**：在保证质量和效率的前提下，提高注册数量和FTD数量。

量化目标（数值待核定）：

1. **效率目标（硬约束）**：单有效FTD获客成本（CPA总支出 ÷ 有效FTD数量）不高于所在市场档位的行业CPA单价中位数——外部行业基准（2026，第三方聚合数据，未一手核实，仅作锚点）：Tier-1市场约$600、Tier-2/3市场约$200；我方适用档位随Q-004首期国家确定，锚点值随Q-007定价评审确认；
2. **增长目标（方向）**：试点期内有效FTD数量逐月上涨，观察窗口与月度目标值待合作方招募规模测算后补充。

### 3.2 核心指标

| 指标         | 定义                                                   |
| ---------- | ---------------------------------------------------- |
| 有效FTD（北极星） | 完成首次入金且满足质量条件的客户；质量条件=入金+交易组合（Q-007方向已确认，数值待评审）      |
| 净新增客户数     | Affiliate链路注册且不与IB归属重合的客户（口径按Q-010：主档唯一识别+KYC身份辅助去重） |

### 3.3 目标之外的约束

- 不重复建设统计分析功能，一律经由IMC（CFD-D-007，开发顺序见CFD-D-010）；
- 优先优化现有系统的用户来源追踪体系。

### 7.3 预期结果

- 有效FTD在保证质量的前提下被完整、正确计量；
- 归属零错配：抽样验证Affiliate与IB归属互不污染；
- 佣金全链路可追溯：每笔佣金能还原到触发事件、检查记录与审批链；
- 无来源流量不被默认归因，不影响合作方计佣公平性；
- 风控事件闭环：风险触发事件被完整识别、处置并留痕（不归因/Hold/人工复核各有记录），无误放行；误判可经申诉复核后恢复，处置结果可查证。

## 8. 风险、权限与例外

评分系统列为P1阶段开发：为各风险事件设计权重，按事件累计计算账户风险分，依据分数对应的风控等级施加相应限制（权重共同设计中）。

| 风险或异常               | 触发条件                           | 处理动作                          | 审批角色         | 证据与恢复方式                     |
| ------------------- | ------------------------------ | ----------------------------- | ------------ | --------------------------- |
| 禁推地区/违规主体申请         | 硬门禁校验命中国家、主体、产品黑名单             | 拒绝申请、阻断注册                     | 风控（硬规则自动）    | 名单记录+到期复评，规则版本可追溯           |
| IB归属客户进入Affiliate链路 | 归因前查询命中既有IB归属                  | 不归因、排除业务统计，保留原始事件并打标          | 系统自动+风控复核    | 排除记录含主档ID/规则/原因码，可审计（Q-011） |
| 虚假/套利流量             | 事件级检查命中：异常点击时序、自动化、设备伪造、代理遮蔽地域 | 人工复核、Hold、不归因                 | 风控           | 原因码+判定证据，可申诉                |
| 同设备批量注册/注册集群        | 同一设备指纹、IP或网段在短时间内集中产生多账户注册，注册时序、来源与关联特征呈集群分布 | 集群账户不归因并纳入评分（P1计入账户风险分）、批量Hold，人工复核后判定计佣资格；共享网络本身不直接等同违规 | 风控（集群确认与解除须审批） | 关联图谱（设备/IP/注册时序）+集群判定口径留痕，误判账户可申诉后恢复计佣 |
| 自荐/亲属关联推广           | 自荐或亲属关联注册/推广                   | 冻结相关佣金、进入调查                   | 风控+业务        | 复核记录、关联调查范围                 |
| 盗卡/拒付/退款            | 支付事件命中拒付、退款、冲销                 | 拒付冲正、佣金追索、限制提现                | 财务+风控        | 支付凭证、追索与恢复流程                |
| 合作方持续违规             | 周期评分落入风险带/重复违规/黑名单确认           | 限流、延迟结算、降级、封禁，按账户风险分对应的风控等级执行 | 业务+风控（封禁须审批） | 名单对象/范围/期限/审批链，申诉与解除机制      |
