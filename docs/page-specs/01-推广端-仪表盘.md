# 页面规范：仪表盘

- 页面id：dash
- 端：客户端（v0.18 更名，原推广方端）
- 菜单：数据总览 › 仪表盘

## 页面目标
推广方登录后第一眼：我能提多少钱、客户激活情况、去哪拿链接。

## 主体
| 区块 | 内容 | 交互 |
|---|---|---|
| 我的推广链接 | 链接文本 + 目标页/语言说明 | 复制（真实复制到剪贴板，按钮短暂变「已复制」，含降级方案）；「深度链接设置」按钮跳转深度链接页（deep） |
| 收益趋势 | 柱状图，随维度切换 | 维度切换：天（近14天）/ 周（近8周）/ 月（近6个月），标题与横轴标签随维度和语言变化 |
