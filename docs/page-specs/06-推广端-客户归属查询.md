# 页面规范：客户归属查询

- 页面id：lookup
- 端：客户端（v0.18 更名，原推广方端）
- 菜单：收益中心 › 客户归属查询

## 页面目标
归属争议自助查询：推广方输入客户标识即可查「这人算不算我的」，不靠工单。

## 主体
| 区块 | 内容 | 交互 |
|---|---|---|
| 查询输入 | 输入框：注册邮箱 / 交易账号 / 投资钱包账号；示例占位 | 「查询」按钮 |
| 结果卡 | 客户编号（C-10241，完整显示）/ 客户邮箱（w***@gmail.com，脱敏）/ 归属状态（已归属到你的账户·绿）/ 归属起始（2026-10-18，首触归因）/ 判定依据（30天归因窗口内首次点击，此后锁定） | - |

## 显示规则
- 客户编号完整显示，编号格式与「客户列表」页一致（C-XXXXX）
- 客户邮箱脱敏：首字符保留 + *** + @域名
