# 页面规范：合作者审核

- 页面id：paudit
- 端：运营管理端
- 菜单：合作者管理 › 合作者审核
- 基线：v0.21 已实现（交互对齐合作者列表；值与业务逻辑不变）

## 页面目标
处理新合作者申请：核对资料完整度 + 风控预检，批准 / 拒绝 / 要求补充材料。

## 统计卡（4张，静态演示值）
| 卡片 | 数值 | 副文字 |
|---|---|---|
| 待审核 | 9 | 3件超48小时（红字催办提示） |
| 本月通过 | 14 | - |
| 本月拒绝 | 3 | - |
| 平均审核时长 | 1.8 天 | - |

## 筛选器（v0.16：对齐合作者列表交互，替换原 chip 形式）
- 默认：收起，点「筛选条件 ▾」展开
  | 字段 | 类型 | 说明 |
  |---|---|---|
  | 状态 | 单选 | 全部 / 待审核 / 已通过 / 已拒绝 |
- 「查询」按钮：点击后筛选生效（按状态过滤表格行）
- 「重置」按钮：清空并立即生效
- 表格下方左下角显示当次查询结果总数「共 N 条」

## 表格（10列，演示5行）
| 列 | 格式 | 交互 |
|---|---|---|
| 申请编号 | 文本 | - |
| 申请人 | 编号+脱敏邮箱 | 申请编号（P-xxxx）+ 脱敏邮箱两行显示；点击邮箱显示/隐藏完整邮箱 |
| 类型 | 标签 | 个人 / 公司 |
| 渠道类型 | 文本 | 网站·内容 / 社媒·KOL / SEM投放 / 线下·经纪 |
| 预计月流量 | 数量 | - |
| 目标国家 | 标签 | - |
| 资料完整度 | 标签(状态) | 3/3完整绿 / 2/3缺流量证明黄 / 1/3缺身份与公司文件红 |
| 风控预检 | 标签(状态) | 无命中绿 / 疑似重复注册黄 / 命中黑名单IP红 |
| 申请日期 | 日期 | - |
| 状态 | 标签(状态) | 待审核蓝 / 已通过绿 / 已拒绝红 |
| 操作 | 按钮 | 待审核行：单「审核」按钮 → 打开详情抽屉，批准/拒绝在抽屉内操作；已通过/已拒绝行：按钮文案「查看」（v0.21），抽屉只读；操作列冻结（sticky）在数据表最右侧 |

## 详情抽屉（v0.16 新增，右侧滑出，仅展示、不改业务）
- 680px 宽、右侧贴边、全高，滑入动画；点击遮罩或「关闭」退出
- 头部：首字母头像 + 申请编号（P-xxxx）+ 申请单号 + 状态标签
- 区块1 基本信息：申请编号、申请人编号、申请人邮箱、推广渠道类型、预计月流量、目标国家、申请日期、状态
- 区块2 审核要点：资料完整度、风控预检
- 待审核行抽屉底部出操作按钮：批准（绿）/ 拒绝（红）/ 补充材料 / 关闭；操作后行状态与抽屉状态同步更新并 toast；已处理行仅展示
- 注：账户类型列已移除——目前只做个人入驻（v0.17）
