# 页面规范：业绩数据

- 页面id：perf
- 端：客户端（v0.18 更名，原推广方端）
- 菜单：数据总览 › 业绩数据
- 基线：v0.13 已实现

## 页面目标
推广方按时间/活动/UTM 查看自己的流量漏斗、客户质量与收益状态，数据每2小时更新。

## 筛选器（右侧抽屉，v0.13）
- 入口：右上「筛选器 (N)」按钮，点击后筛选面板从右侧滑出（带遮罩，点遮罩/✕关闭）
- 抽屉内字段：
| 字段 | 类型 | 选项 |
|---|---|---|
| 时间 | 点击弹出日历 | 起止两个日期框，点击弹自选日历（月份网格、前后翻月、点选写回、选中高亮+今天描边），默认 2026-09-23 ~ 2026-10-22 |
| 活动 | 下拉单选 | 全部活动 / 十月 Telegram 投放 / 财经博客内容位 / 九月信息流测试 |
| UTM 来源 utm_source | 多选chips | 全部 / Telegram / Facebook / 谷歌广告 / 推荐链接 |
| UTM 媒介 utm_medium | 多选chips | 全部 / 社交媒体 / 竞价广告 / 推荐流量 |
| UTM 活动 utm_campaign | 多选chips | 全部 / 三个活动名 |
| UTM 关键词 utm_term | 多选chips | 全部 / 外汇 / 交易 |
| UTM 内容 utm_content | 多选chips | 全部 / 横幅 A 版 / 视频 B 版 |
- UTM 五组每组带「全部」chip + 独立多选；组标题中文 + 右侧灰色参数英文名
- 底部按钮：重置（恢复默认，计数=1）/ 应用（关闭抽屉，按钮计数联动：时间恒计1，活动非全部+1，每个 UTM 组有选中各+1）
- 注：计数为演示联动，表格数据不随筛选实际变化

## 动态分组表格（v0.8，v0.13 标签中文化）
- 左上角为分组维度 chips：默认「日期」；「＋ 添加分组」点击弹出维度菜单
- 可选分组维度（暂定 7 个，中文标签）：日期 / 国家 / UTM 来源 / UTM 媒介 / UTM 活动 / UTM 关键词 / UTM 内容
- 交互：菜单点选即添加为分组 chip；每个分组 chip 带 × 可移除；表格列 = 当前分组维度列（在前）+ 指标列（在后），数据按分组聚合
- 分组值中文化：国家（马来西亚等）、UTM 来源（谷歌广告/推荐链接）、媒介（社交媒体/竞价广告/推荐流量）、关键词（外汇/交易）、内容（横幅 A 版/视频 B 版），与客户列表口径一致；切英文恢复英文参数值
- 全部分组移除后显示一行「全部」总计（演示支持）

## 指标列（17列，固定）——客户三态保持，资金四态改为三态
| 列组 | 列 |
|---|---|
| 触达获客 | 印象 / 安装 / 被拦截的安装 / 点击量 / 点击到达率 / 注册量 |
| 入金转化 | 首次入金 / 首次入金金额 / 开始交易 / 合格客户 |
| 客户三态 | 忠诚客户 / 持有客户 / 黑名单客户 |
| 资金三态 | 预计收益 / 已拒绝利润 / 暂扣利润 + EPC |

- 设计要点：被拦截安装直接进漏斗（风控透明化）；客户三态与资金三态两条线并行展示
