## 页面目标
CPA 全链路业务参数的配置化入口（即 Q-007 数值的承载页，当前为示例值，评审后以此页为准替换）。

## 主体（5组参数表，每组3列：参数 / 当前值（输入框可编辑）/ 说明，共23项）

### 组1 合格客户判定
| 参数 | 示例值 | 说明 |
|---|---|---|
| 最低首次入金 | $50 | 低于此不计有效FTD |
| 有效FTD交易手数 | 2手 | 达标期内累计 |
| 有效交易金额（累计） | $500 | 达标期内累计 |
| 达标期限（自注册起） | 90天 | 超期不再具备资格 |
| 忠诚客户窗口 | 首存后2个自然月内 | 仅真实交易，模拟盘不计 |

### 组2 结算与提现
| 参数 | 示例值 | 说明 |
|---|---|---|
| 动态Hold初始时长 | 1天 | 风险分递增映射待评审 |
| 动态Hold冻结阈值 | 超过30天 | 转冻结并进入人工审核 |
| 结算周期 | 日结 | 不设最低提现限制 |
| CPA档位 | 按国家×Tier定价 | 按客户国家与合作方档位匹配单价 |

### 组3 归因规则
| 参数 | 示例值 | 说明 |
|---|---|---|
| 归因窗口 | 30天 | 窗口内首触决定归属 |
| 归属锁定 | 首次点击即锁定 | 锁定后不因后续点击变更 |
| 非活跃回收 | 90天 | 无交易超此天数可回收归属 |

### 组4 风控阈值
| 参数 | 示例值 | 说明 |
|---|---|---|
| 风险分风险带 | R0 0-19 / R1 20-39 / R2 40-59 / R3 60-79 / R4 80-100 | 风险事件加分累计，越高越险 |
| 风险带处置 | R3 限流+人工复核 / R4 暂扣佣金+封禁评估 | 落入对应风险带执行 |
| 归因基准 | 按国家×平台维护 | 见归因限制配置页 |

### 组5 时限与申诉（试点内部目标值）
| 参数 | 示例值 | 说明 |
|---|---|---|
| H1有效期 | 30天 | 讨论稿参考值，待复核 |
| H1复核频率 | 每周 | 不自动无限续期 |
| 申诉期 | 15自然日 | 自拒绝通知起算 |
| 申诉复核时限 | 5工作日 | 超时升级处理 |
| Hold延期处理 | 重大风险事件可追加 | 延期须留痕并通知合作方 |
| 超期Hold处理 | 超过30天转冻结 | 进入人工审核，不自动放行 |
| 联合审批 | 合规+财务 | 冲正、追回、例外放行适用 |
