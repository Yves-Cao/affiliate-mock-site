# 页面规范：渠道分析

- 页面id：chan
- 端：运营管理端
- 菜单：数据统计 › 渠道分析
- 基线：v0.3 已实现

## 页面目标
合作方效率排行对比：支撑「哪个渠道值得留、哪个要处理」的运营决策。

## 筛选器
- 默认：展示（chip 形式，切换排序）：按合格客户 / 按收益 / 按EPC / 按拒付率

## 表格（9列：合作方排行，演示6行）
| 列 | 格式 | 交互 |
|---|---|---|
| 排名 | 数字 | - |
| 合作者 | 文本 | - |
| 点击 | 数量 | - |
| 注册 | 数量 | - |
| 合格客户 | 数量 | - |
| 注册→合格 | 百分比 | - |
| 拒付率 | 百分比 | - |
| 本月收益 | 金额 | - |
| 环比 | 涨跌 | ▲绿 / ▼红 |
