# 页面规范：合作者列表（★ 交互基线）

- 页面id：plist
- 端：运营管理端
- 菜单：合作者管理 › 合作者列表
- 基线：v0.16 已实现

## 页面目标

运营查看全部合作者的状态、业绩与风险分总览，一键筛出问题合作者并查看详情。

## 统计卡（4张，数字由列表数据实时计算）

| 卡片     | 数值口径             | 点击行为            | 悬浮说明           |
| ------ | ---------------- | --------------- | -------------- |
| 合作者总量  | 全部合作者数           | 点击筛选（=清空筛选显示全部） | -              |
| 活跃     | 最近30个自然日内活跃的合作者数 | 点击筛选            | 30个自然日内活跃合作者   |
| 封禁     | 状态=封禁的数量         | 点击筛选            | -              |
| 高风险合作者 | 风险分≥60（R3+）的数量 | 点击筛选            | 卡片副文字：风险分 ≥ 60 · R3+ |

- 点击规则：点中的卡高亮描边，再点一次取消；卡片与筛选栏控件双向同步

## 风险分（本页核心概念，其他页引用同名概念；v0.15 按风控方案讨论稿反转口径）

- PartnerRiskScore 0-100，按六向量加权累计（身份合规 20% / 流量归因 20% / 客户经济 20% / 交易行为 15% / 支付资金 15% / 伙伴行为 10%），分数越高风险越高
- 风险带：R0 正常 0-19 绿 / R1 观察 20-39 蓝 / R2 限制 40-59 橙 / R3 高风险 60-79 红 / R4 阻断 80-100 深红
- 加分事件示例：佣金冲正 +15 / 无效流量(脚本特征) +12 / KYC复检失败 +12 / 推广材料违规 +10 / 归因低于基准预警 +8 / 长期未活跃 +6 / 客户投诉 +5
- 展示格式：分数条 + 「分数 · R带」（如 72 · R3）

## 筛选器（v0.16：暂存 → 查询生效）

- 默认：收起，点「筛选条件 ▾」展开  
  | 字段 | 类型 | 说明 |  
  |---|---|---|  
  | 用户编号 | 文本 | 暂存不即时筛（编号/名称/邮箱模糊匹配）；回车=查询 |  
  | 国家 | 多选 | 勾选暂存，按钮显示已选数量；「全部」再点一次=取消全选（清空所选，查询后列表为空），手动勾满自动回到全选态 |  
  | 状态 | 单选 | 全部 / 启用 / 暂停 / 封禁 |  
  | 活跃 | 单选 | 全部 / 30日内活跃 / 30日内未活跃 |
- 「查询」按钮：点击后筛选条件才生效（数据量大时避免每次点击都查询）
- 「重置」按钮：一键清空全部筛选并立即生效
- 表头「国家」列也可直接点开多选下拉，为快捷筛选、改动即时生效，与筛选栏联动
- 统计卡点击仍即时生效（并同步回筛选栏）

## 表格（14列）

| 列       | 格式     | 交互                |
| ------- | ------ | ----------------- |
| 编号      | 文本     | -                 |
| 邮箱      | 脱敏邮箱   | 脱敏（点击显示完整/再点隐藏）   |
| 国家      | 标签     | 表头点击=多选筛选下拉（即时生效） |
| 入驻日期    | 日期     | -                 |
| 状态      | 标签(状态) | 启用绿 / 暂停黄 / 封禁红   |
| 推荐客户数量  | 数量     | -                 |
| 有效FTD客户 | 数量     | -                 |
| 注册-FTD  | 百分比    | =有效FTD÷推荐客户       |
| FTD-FTQ | 百分比    | =合格客户÷有效FTD       |
| 累计收益    | 金额     | -                 |
| 可提现余额   | 金额     | -                 |
| 风险分     | 分数条+标签 | -                 |
| 最近活跃    | 日期     | 当日显示「今日」、昨日显示「昨日」 |
| 详情      | 按钮     | 点击右侧抽屉（合作者详情）；操作列冻结（sticky）在数据表最右侧，横向滚动始终可见 |

## 详情抽屉（v0.16：由居中弹窗改为右侧滑出抽屉）

- 680px 宽、右侧贴边、全高，滑入动画；点击遮罩或「关闭」退出
- 头部：首字母头像 + 名称 + 编号/类型/国家 + 状态标签
- 区块1 基本信息：编号、邮箱（完整）、国家、入驻日期、状态、二级渠道数
- 区块2 业绩：点击、推荐客户、有效FTD、合格客户、注册-FTD、FTD-FTQ、EPC
- 区块3 收益：累计收益、可提现余额、暂扣中、累计已提现
- 区块4 风险分：分数条 + 当前分+R带 + 口径说明 + 加分事件列表（日期/事件/加分）
- 切换中英文时抽屉内容同步翻译

## 分页

- 每页：10；页码 + 前后翻页；左下角显示当次查询结果总数「共 N 条」（v0.16：不再显示固定每页条数，筛选面板内的总数展示已移除）
