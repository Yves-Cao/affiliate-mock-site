# 页面规范：出金审批

- 页面id：payout
- 端：运营管理端
- 菜单：运营管理 › 出金审批
- 基线：v0.17 已实现

## 页面目标
推广方提现申请的审批队列——资金出账前的最后一道闸。与推广端 21-提现、05-结算流水口径一致；18-账户配置中财务角色权限已含「提现审批」，本页是其承载页。

## 统计卡（3张）
| 卡片 | 数值 | 副文字 |
|---|---|---|
| 待审批 | 5 | 本周新增 |
| 本周出金 | $18,200 | 环比 ▲ 12% |
| 拒绝率 | 1.5% | 环比 ▼ 0.3pct |

## 表格（9列，演示4~5行）
| 列 | 格式 | 交互 |
|---|---|---|
| 申请单号 | 文本 | 如 WD-20261022-001 |
| 合作者 | 编号+脱敏邮箱 | 名称+编号（P-xxxx），下方补脱敏邮箱（v0.17） |
| 出金方式 | 标签 | 电汇 / 其他（示例值，渠道待定） |
| 金额 | 金额 | - |
| 手续费 | 金额 | 因方式而异（示例值） |
| 申请日期 | 日期 | - |
| 风险分 | 标签 | R0-R4 风险带（如 92 · R4 深红） |
| 状态 | 标签(状态) | 待审批蓝 / 已支付绿 / 已拒绝红 |
| 操作 | 按钮 | 批准（绿）/ 拒绝（红）；高风险（风险分≥60 · R3+）批准前弹确认；拒绝弹原因码弹窗 |

## 弹窗
- 高风险批准确认：触发=风险分≥60（R3+）的行点「批准」；内容=风险提示+加分事件摘要+仍要批准

## 与其他页的关系
- 推广端 21-提现：申请发起端；05-收益与提现：流水记录；14-财务统计：出金汇总口径一致
