# 页面规范：黑名单管理

- 页面id：bl
- 端：运营管理端
- 菜单：运营管理 › 黑名单管理
- 基线：v0.17 已实现（按风控方案讨论稿第 7 章新增）

## 页面目标
H0 / H1 / H2 三层名单的全生命周期台账：生效、观察、申诉、解除、到期，处置可追溯。

## 统计卡（3张）
| 卡片 | 数值 | 副文字 |
|---|---|---|
| H0 确认阻断 | 4 | 风控 + 合规双人审批生效 |
| H1 观察名单 | 7 | 2 条本周到期 · 每周复核 |
| 申诉中 | 2 | 复核时限 5 个工作日 |

## 台账表（9列）
| 列 | 格式 | 说明 |
|---|---|---|
| 编号 | 文本 | BL-XXXX |
| 对象 | 编号+脱敏邮箱 | 客户：完整 C-编号 + 脱敏邮箱两行；合作者：名称+编号 + 脱敏邮箱；Sub ID：文本（v0.17 口径） |
| 对象类型 | 标签 | 客户 / Sub ID / 合作者 |
| 层级 | 标签 | H0 确认阻断（红）/ H1 观察名单（橙）/ H2 规则提醒（蓝） |
| 命中规则 | 文本 | 如「自我推荐（复检确认）」「盗卡拒付 2 笔」 |
| 状态 | 标签 | 生效中 / 观察中 / 申诉中 / 已到期解除 |
| 生效日期 | 日期 | - |
| 到期日 | 日期 | H0 显示「长期」；H1 默认 30 天 |
| 操作 | 按钮 | 详情 / 解除 / 延期（H1）；申诉复核（申诉中行） |

## 底部规则说明条
- H0 与永久封禁需风控 + 合规双人审批（两个不同账号）
- H1 默认 30 天、每周复核、可提前解除；延期需审批、不自动续期；到期未延期自动失效
- 完整状态机：候选 → 调查 → 确认 / 观察 → 申诉 → 解除 / 到期

## 弹窗
- 无独立弹窗；申诉复核点击 toast 提示创建复核任务（合规 · 5 个工作日内）
