# 页面规范：CPA档位表

- 页面id：tier
- 端：运营管理端
- 菜单：系统配置 › CPA档位
- 基线：v0.14 已实现

## 页面目标
CPA 单价的核心配置页：按国家分档 × 合作方档位（Tier）定价。Q-007「每合格客户付多少」的正式承载页；16-参数配置中「CPA档位」一行跳转至此。

## 主体（2个区块）

### 区块1 国家分档（国家 → 定价档）
| 列 | 格式 | 交互 |
|---|---|---|
| 国家 | 标签 | 表头点击=多选筛选下拉 |
| 定价档 | 标签 | Tier 1 / Tier 2 / Tier 3 |
| 示例市场 | 文本 | 如 Tier1：英国/澳大利亚 |
| 生效日期 | 日期 | - |
| 操作 | 按钮 | 调档（点击弹窗） |

- 演示9~12国，覆盖三个Tier；Q-009 未决前「国家」判定字段口径悬浮说明标注

### 区块2 定价矩阵（定价档 × 合作方档位 → 单价）
| 定价档 | 铜 | 银 | 金（示例合作方档位） |
|---|---|---|---|
| Tier 1 | $300 | $350 | $400 |
| Tier 2 | $200 | $250 | $300 |
| Tier 3 | $120 | $160 | $200 |

- 单元格为可编辑输入框（金额格式）；全部为示例值，评审后替换
- 底部：取消 / 保存（按钮）；保存后记录生效版本

## 与其他页的关系
- 16-参数配置：通用参数（Hold期/结算周期等）在其页，单价数值在本页
- 09-结算审批/14-财务统计：审批与汇总金额按本页单价计算

## 弹窗
- 国家调档：触发=「调档」；内容=国家+新定价档下拉+生效日期+说明

## 分页
- 区块1 表格：每页10
