# 页面规范：归因限制配置

- 页面id：attr
- 端：运营管理端
- 菜单：运营管理 › 归因限制配置
- 基线：v0.3 已实现

## 页面目标
按国家×平台维护流量基准（Exness 式公开成表），低于基准暂停新客归因，程序参照 SC 协议 10.2。

## 主体

### 基准表
| 列 | 格式 | 交互 |
|---|---|---|
| 国家 | 标签 | - |
| 平台 | 文本 | Web / 移动端 |
| 最低FTD/点击比 | 文本（如 1 FTD / 5,000 点击） | - |
| 最低FTD/曝光比 | 文本 | - |
| 状态 | 标签(状态) | 正常绿 / 2家接近基准黄 / 已暂停红 |
| 操作 | 按钮 | 编辑 |

### 触发与恢复机制（4步卡）
1. 低于基准：国家×平台组合跌破基准线
2. 通知+宽限：向合作方发出书面通知，不少于24小时恢复宽限期
3. 暂停归因：宽限期后仍低于基准则暂停新客归因；已累计佣金不受影响
4. 自动恢复：表现回升后自动恢复；全程留痕可审计
