# 页面规范：操作审计日志

- 页面id：audit
- 端：运营管理端
- 菜单：系统配置 › 操作日志
- 基线：v0.14 已实现

## 页面目标
敏感操作留痕的只读查询：冲正、归属调整、出金审批、配置变更等合规留痕（参考 SC 协议 10.2 留痕程序思路）。

## 筛选器
- 默认：收起，点「筛选条件 ▾」展开
| 字段 | 类型 | 选项 |
|---|---|---|
| 操作人 | 文本 | 输入即筛 |
| 模块 | 单选 | 全部 / 结算审批 / 出金审批 / 风控处置 / 归因配置 / 参数配置 / 档位表 |
| 日期区间 | 日期 | 起止 |

## 表格（6列，演示6~8行）
| 列 | 格式 | 交互 |
|---|---|---|
| 时间 | 日期时间 | - |
| 操作人 | 文本 | - |
| 角色 | 标签 | 超管 / 运营 / 风控 / 财务（与18-账户配置角色一致） |
| 模块 | 标签 | 同筛选器枚举 |
| 动作摘要 | 文本 | 如「拒绝 WD-20261022-003，原因：KYC复检失败」 |
| 结果 | 标签(状态) | 成功绿 / 失败红 |

- 只读页：无操作按钮、无弹窗
