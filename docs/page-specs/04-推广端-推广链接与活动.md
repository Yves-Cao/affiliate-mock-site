# 页面规范：推广链接与活动

- 页面id：promo
- 端：客户端（v0.18 更名，原推广方端）
- 菜单：推广管理 › 推广链接与活动
- 基线：v0.5 已实现

## 页面目标
链接与渠道管理：活动（链接分组）与 Sub ID（下级渠道登记）。深度链接已拆分为独立菜单页（见 04b）。

## 主体（2个tab）

### tab1 活动（默认）
| 列 | 格式 | 交互 |
|---|---|---|
| 活动 | 文本 | - |
| 链接 | 链接 | - |
| 状态 | 标签(状态) | 启用绿 / 暂停黄 |
| 注册 / 合格 / 预计收益 | 数量/金额 | - |
- 「+ 创建新活动」按钮 → 点击弹窗（新建活动）

### tab2 Sub ID（二级发布者）
概要卡3张：Sub ID 总数 / 启用中 / 已封禁
| 列 | 格式 | 交互 |
|---|---|---|
| Sub ID | 文本 | - |
| 链接状态 | 标签(状态) | 启用绿 / 已封禁红 |
| 更新日期 | 日期 | - |
| 操作 | 按钮 | 封禁 / 解封（点击即切换状态） |

## 弹窗：新建活动
- 触发：「+ 创建新活动」按钮
- 内容：活动名称输入框（唯一字段，活动=链接分组，不做预算/日期/出价）+ 取消/保存
