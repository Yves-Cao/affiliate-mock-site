# 页面规范：账户配置

- 页面id：acct
- 端：运营管理端
- 菜单：系统配置 › 账户配置
- 基线：v0.15 已实现（原口径不变）v0.3 已实现

## 页面目标
后台用户与角色权限管理（RBAC 演示）。

## 主体（2个tab）

### tab1 用户（默认）
- 「+ 新增用户」按钮
| 列 | 格式 | 交互 |
|---|---|---|
| 账号 | 文本（邮箱式） | - |
| 姓名 | 文本 | - |
| 角色 | 标签 | 超管 / 运营 / 风控 / 财务 / 客服 |
| 部门 | 文本 | - |
| 状态 | 标签(状态) | 启用绿 / 停用灰 |
| 最近登录 | 日期 | - |
| 操作 | 按钮 | 停用 / 启用（点击即切换） |

### tab2 角色权限
| 列 | 格式 | 交互 |
|---|---|---|
| 角色 | 标签 | 超管 / 运营 / 风控 / 财务 / 客服 |
| 成员数 | 数字 | - |
| 权限范围 | 文本（如：全部权限 / 合作者管理·审核·数据统计 / 风控事件·归因限制 / 结算审批·提现审批·财务统计 / 合作方列表只读） | - |
| 操作 | 按钮 | 编辑（占位） |

- 无
