# 页面规范：素材库

- 页面id：assets
- 端：客户端（v0.18 更名，原推广方端）
- 菜单：推广管理 › 素材库
- 基线：待实现（新增）

## 页面目标
推广方获取投放素材；未接受《推广行为准则》前锁定下载——准则门禁是防违规投放的第一道闸。

## 准则门禁（本页核心交互，置于素材区之上）
- 未接受准则：素材区整体锁定（半透明遮罩），显示提示条「请先阅读并接受《推广行为准则》后方可下载素材」+「阅读并接受准则」按钮 → 跳转(apply) 准则接受步骤（或站内准则页）
- 已接受准则：遮罩消失，素材区正常使用
- 演示默认：未接受状态（便于评审看门禁效果）

## 筛选器
- 默认：展示（chip 形式）：全部 / 网幅 / 视频 / 落地页 / GIF / 标志
- 点击筛选：点击 chip 联动筛选下方素材网格，再点取消
