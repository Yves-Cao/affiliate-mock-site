# 页面规范 · 使用说明（页面契约）

> **用法（2026-10-23起，CFD-D-016）**：直接修改某一页的 md → 保存 → 提出页面或接口变更。
> 后续不再继续升版评审原型；本目录作为页面结构的唯一事实来源，用于维护OpenAPI、Mock场景和研发实现。冻结原型v0.21仅作视觉与交互参考，原型与规范冲突时以规范为准。

## 一、通用规则（所有页面默认遵守）

1. **正文即现状**：每页规范列的是该页当前结构；正文没提到的部分保持现状。
2. **改法**：删除一行 = 删除该元素；新增一行 = 新增元素；改文字 = 改文案。2026-10-23前该规则用于生成原型HTML；2026-10-23后同步用于契约、Mock数据和研发实现。
3. **数值**：页面里出现的金额、天数、比例均为示例值；正式数值由「参数配置」页统一管理，评审后替换，不写死。
4. **全局框架**（顶部栏 + 左侧菜单）不在单页规范里，要改框架在本文件「四、全局框架」处写。
5. 规范里写「待定」的项 = 你还没想好，我先按现状做并留扩展位。

## 二、词表（写规范时用这些词，我能精确识别）

### 字段类型
`文本` / `单选` / `多选` / `日期` / `数字`

### 交互动作
| 词 | 含义 |
|---|---|
| 点击筛选 | 点击后联动筛选下方表格/列表，再点取消 |
| 点击弹窗 | 点击打开弹窗 |
| 悬浮说明 | 鼠标悬浮显示提示气泡 |
| 脱敏 | 默认打码显示，点击显示完整、再点隐藏 |
| 复制 | 点击复制到剪贴板（按钮短暂变「已复制」） |
| 跳转(页面id) | 点击跳转到指定页面 |
| tab切换 | 页内标签页切换 |

### 显示格式
`金额` / `百分比` / `日期` / `数量` / `标签(状态)` / `脱敏邮箱` / `分数条` / `链接`

### 状态与颜色（写状态名即可，颜色自动映射）
- **绿**：启用 / 通过 / 已支付 / 正常 / 已发布
- **黄**：暂停 / 待定 / 中风险 / 暂扣 / 接近基准
- **红**：封禁 / 拒绝 / 高风险 / 失败 / 已暂停归因
- **蓝**：待审核 / 处理中 / 进行中
- **灰**：草稿 / 停用 / 未提交 / 未入金

## 三、页面规范统一结构

```
# 页面规范：页面名
- 页面id / 端 / 菜单 / 基线版本

## 页面目标        ← 一句话：给谁看、解决什么
## 统计卡          ← 有则写：卡片 | 数值口径 | 点击行为 | 悬浮说明
## 筛选器          ← 有则写：默认收起/展示；字段 | 类型 | 选项
## 表格/主体       ← 列 | 格式 | 交互；非表格页写区块结构
## 弹窗            ← 有则写：触发方式 + 弹窗内区块
## 分页            ← 表格型页面：每页条数
## 修改记录        ← 你改 md 时随手记一行（正文为准，此处仅备忘）
```

## 四、全局框架（要改框架改这里）

- **顶部栏**：面包屑（随端+页面更新）｜ 可提现余额（仅客户端显示）｜ 帮助中心 ｜ 通知（红点）｜ 中文/EN 切换 ｜ 用户头像
- **左侧菜单**：父子两级、可折叠；父菜单图标+箭头，子菜单缩进竖线；切页面自动展开所在组；侧栏最底部固定「资料完善」入口（仅客户端显示，进入驻申请页；v0.20 由「实名激活」更名）
- **未实名提示条（v0.18 规则）**：客户端顶栏用户区下方显示警示条（实名认证 KYC 未完成提醒），右侧「知道了」（本次会话暂时消失，刷新恢复）+「去完善」（跳转入驻申请页）；申请页内不显示；运营管理端不显示；完成 KYC 后永久消失
- **页面切换**：侧栏点子菜单跳转；运营端默认落在「合作者列表」、客户端默认落在「仪表盘」
- **端名称（v0.18）**：「推广方端」已更名为「客户端」（侧栏切换、面包屑、相关文案；运营管理端不变）
- **筛选条件折叠面板（v0.9 全站规则，v0.16 修订）**：凡页内筛选器（chips、输入框、下拉等）一律包进统一折叠面板——头部为「箭头 + 筛选条件」，点击折叠/展开，折叠后只显示「筛选条件」一行；已应用于客户列表 / 合作者列表 / 合作者审核 / 风控事件处置 / 规则配置 / 素材库。业绩数据为右侧抽屉式筛选，不属此类
- **查询/重置按钮（v0.16 规则，适用于数据量大的列表页）**：合作者列表与合作者审核的筛选面板内改动先「暂存」，点「查询」才生效、点「重置」清空并立即生效；表头列内快捷下拉（如国家）保持即时生效；表格左下角显示当次查询结果总数
- **右侧详情抽屉（v0.16 规则）**：合作者列表与合作者审核的行详情采用右侧滑出抽屉（680px、全高、点遮罩关闭）；详情操作列冻结（sticky）在数据表最右侧
- **编号 + 脱敏邮箱口径（v0.17 全站规则）**：凡显示客户或合作者的数据表，一律「完整编号 + 脱敏邮箱」两行式——编号不脱敏（C-xxxxx / P-xxxx / 申请编号），邮箱脱敏（u***@gmail.com），可点击显隐完整邮箱。已应用于客户列表 / 合作者列表 / 合作者审核（申请人列）/ 结算审批 / 出金审批 / 风控事件处置（客户对象）/ 黑名单管理 / 归属查询；行操作多步时合并为单入口按钮（如审核页「审核」），操作移入抽屉内
- **双语**：全站中英切换，表格枚举值、国家名、状态一并翻译
- **分页**：表格型页面默认 10 条/页（合作者列表 / 合作者审核左下角改显当次查询总数）
