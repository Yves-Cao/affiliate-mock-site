# 页面规范：客户列表

- 页面id：clients
- 端：客户端（v0.18 更名，原推广方端）
- 菜单：数据总览 › 客户列表
- 基线：v0.15 已实现

## 页面目标
客户级明细：每个客户从哪来（证据链）、是否合格（判定链）、钱在什么状态（资金链）。

## 筛选器（v0.9 起为「筛选条件」折叠面板）
| 字段 | 类型 |
|---|---|
| 注册时间 | 单选chip（默认：近30天） |
| 忠诚客户 | 单选chip（全部/是/否） |
| KYC | 单选chip（全部/通过/未提交/失败） |
| 资格日期 | 单选chip |

## 表格（20列，演示7行）
| 列组 | 列 | 说明 |
|---|---|---|
| 身份 | 客户编号 / 邮箱 | 编号完整显示（C-10241 式）；邮箱脱敏（w***@gmail.com 式） |
| 判定 | 状态（含 ? 悬浮）/ 注册日期 / 国家 / 平台 / KYC | 状态后加「?」悬浮说明完整数据流转节点链：注册 → 首次入金 → 开始交易 → 合格判定 → Hold 观察（30天）→ 月度结算 → 已支付，并按状态高亮当前节点（合格 / 持有 / 注册未入金 / 黑名单四式文案） |
| 归因证据 | UTM Source / UTM Medium / UTM Campaign / UTM Term / UTM Content | 五个 UTM 参数各一列，参数值显示中文（EN 显示对应英文），如 google_cpc→谷歌广告、camp1→十月 Telegram 投放 |
| 质量 | 忠诚客户 / 资格生效日期 / Tier / Sub ID | - |
| 资金 | 预计 / 已付 / 已拒 / 暂扣 | 钱四态逐客户展示 |
