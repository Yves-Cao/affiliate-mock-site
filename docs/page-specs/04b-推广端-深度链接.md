# 页面规范：深度链接

- 页面id：deep
- 端：客户端（v0.18 更名，原推广方端）
- 菜单：推广管理 › 深度链接
- 基线：v0.11 已实现（v0.5 新增独立菜单；v0.11 移动端补语言）

## 页面目标
按目标页与语言生成直达链接，跳过中间页直达指定落地页。分电脑端和移动端两种。

## 主体（两栏面板）

### 左栏 电脑端深度链接
| 控件 | 类型 | 选项 |
|---|---|---|
| 目标页 | 下拉 | 注册页 / 首页 / Standard·MT5开户页 / Pro·MT4开户页 / Zero·MT5开户页 |
| 语言 | 下拉 | 简体中文 / English / ไทย / Tiếng Việt |

- 链接随选择联动生成（路径段 + lang 参数）
- 「复制链接」按钮：真实复制当前生成的链接

### 右栏 移动端深度链接
| 控件 | 类型 | 选项 |
|---|---|---|
| 目标系统 | 下拉 | iOS (App Store) / Android (Google Play) |
| 目标页 | 下拉 | 同电脑端5项 |
| 语言 | 下拉 | 简体中文 / English / ไทย / Tiếng Việt（与电脑端一致） |

- 链接随选择联动生成（os 段 + 目标页段 + lang 参数）
- 「复制链接」按钮：真实复制
