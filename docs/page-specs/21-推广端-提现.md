## 页面目标
提现独立入口，主体留空占位：支付渠道与门槛尚未确定（关联 Q-007/待决项），正式方案确认后填充出金表单。

## 主体（2个tab）

### tab1 出金（默认，占位）
- 内容留空：显示占位区块「出金方案确认后开放」+ 说明文字「支付渠道与手续费待定；已确认不设最低提现门槛」
- 不做输入框、不做按钮（未确认不设默认值）

### tab2 记录
| 列 | 格式 | 交互 |
|---|---|---|
| 申请日期 | 日期 | - |
| 方式 | 文本 | 电汇 / 其他（示例值） |
| 金额 | 金额 | - |
| 状态 | 标签(状态) | 已支付绿 / 处理中蓝 / 已拒绝红 |
| 备注 | 文本 | 如「尾号6621」 |

- 记录示例3~5行，与 05-收益与提现 结算流水中「提现」类型条目口径一致

## 与 05-收益与提现 的关系
- 05 页保留余额与结算流水总览；本页是出金操作与提现记录的独立入口。两者是否合并以评审为准
