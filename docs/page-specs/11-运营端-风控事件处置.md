# 页面规范：风控事件处置

- 页面id：risk
- 端：运营管理端
- 菜单：运营管理 › 风控事件处置
- 基线：v0.17 已实现

## 页面目标
事件级风控检查与处置：从发现到处置动作，与资金处置联动。

## 筛选器
- 默认：展示（chip 形式）：全部 / 自我推荐 / 刷量流量 / 来源违规 / KYC失败

## 表格（8列，演示5行）
| 列 | 格式 | 交互 |
|---|---|---|
| 事件 | 文本（疑似自我推荐等） | - |
| 类型 | 标签 | 自我推荐 / 刷量脚本 / 流量来源违规 / KYC复检失败 / 盗卡拒付 / 对冲·异常交易 / 归因劫持(Cookie Stuffing) / 禁推地区 / 品牌词冒用 / 重复身份 |
| 对象 | 编号+脱敏邮箱（客户时）/ Campaign 名 | 对象为客户时显示完整 C-编号 + 脱敏邮箱两行（v0.17 全站口径）；Campaign/Sub ID 行保持文本 |
| 证据 | 文本（如注册IP与合作方登录IP重合≥2次） | - |
| 风险分 | 标签 | 「分数 · R带」（如 88 · R4）；命中硬门禁的事件不进评分，直接处置 |
| 建议处置 | 文本 | 按 H0 确认阻断 / H1 观察名单 / H2 规则提醒 分层（如「H0 确认阻断 + 拒付」「H1 观察名单（30 天）」「H2 警告 + 限期整改」）；已付追回标注合规确认 + 财务批准 |
| 状态 | 标签(状态) | 已处置绿 / 处理中蓝 |
