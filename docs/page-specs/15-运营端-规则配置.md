# 页面规范：规则配置

- 页面id：rule
- 端：运营管理端
- 菜单：系统配置 › 规则配置
- 基线：v0.3 已实现

## 页面目标
对外协议、准则、手册、FAQ 的统一管理：版本化、发布通知、多语言同步。

## 筛选器
- 默认：展示（chip 形式）：全部类型 / 协议 / 准则 / 手册 / FAQ；「+ 新建文档」按钮

## 表格（8列8行：8份文档）
| 列 | 格式 | 交互 |
|---|---|---|
| 文档 | 文本 | 主协议 / 推广行为准则(广告政策) / 客户归属与佣金规则 / 拒付与冲正规则 / 隐私政策与Cookie告知 / 新手手册×2 / 归因限制与结算FAQ |
| 类型 | 标签 | 协议 / 准则 / 手册 / FAQ |
| 适用范围 | 文本 | 全部合作方 / 全部用户 / 新合作方 |
| 语言版本 | 文本 | 中文·英文 等 |
| 版本 | 文本（如 v2.1） | - |
| 更新时间 | 日期 | - |
| 状态 | 标签(状态) | 已发布绿 / 草稿灰 |
| 操作 | 按钮 | 发布（草稿行）/ 历史 |

### 发布机制（3卡）
| 机制 | 说明 |
|---|---|
| 版本管理 | 每次编辑生成新版本，历史可追溯可回滚 |
| 生效与通知 | 发布后站内通知合作方；重大条款需重新接受 |
| 多语言同步 | 各语言版本独立维护，发布时校验完整性 |
