# 页面规范：菜单配置

- 页面id：mconfig
- 端：运营管理端
- 菜单：系统配置 › 菜单配置
- 基线：v0.3 已实现

## 页面目标
后台菜单的路由、启用状态、可见角色与排序管理。

## 主体
- 「+ 新增菜单」按钮

## 表格（6列，演示8行）
| 列 | 格式 | 交互 |
|---|---|---|
| 菜单 | 文本 | 合作者列表 / 合作者审核 / 结算审批 / 归因限制 / 风控事件 / 数据统计 / Postback集成 / 系统配置 |
| 路由 | 链接（/partners 式） | - |
| 状态 | 标签(状态) | 启用绿 / 隐藏灰 |
| 可见角色 | 文本 | 运营 / 财务 / 风控 / 超管 / 客服组合 |
| 排序 | 数字 | - |
| 操作 | 按钮 | 编辑（占位） |
