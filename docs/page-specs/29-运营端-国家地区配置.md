# 页面规范：国家地区配置

- 页面id：geo
- 端：运营管理端
- 菜单：系统配置 › 国家地区
- 基线：v0.14 已实现

## 页面目标
分国运营的统一入口：受限国家清单（Q-004 直接参考）、分国参数跳转（归因基准、定价档）。Q-009 国家判定字段未决前，仅做清单与跳转展示。

## 筛选器
- 默认：展示（chip 形式）：全部 / 正常 / 受限 / 禁止

## 表格（6列，演示9~12国）
| 列 | 格式 | 交互 |
|---|---|---|
| 国家 | 标签 | 表头点击=多选筛选下拉 |
| 合作方准入 | 标签(状态) | 开放绿 / 受限黄 / 禁止红 |
| 客户准入 | 标签(状态) | 开放绿 / 受限黄 / 禁止红（与合作方准入分开——竞品为两份清单） |
| 定价档 | 标签 | Tier 1/2/3（点击跳转(tier)） |
| 归因基准 | 链接 | 点击跳转(attr) |
| 备注 | 文本 | 如「零售客户受限」 |

## 与其他页的关系
- 23-CPA档位表：定价档定义在彼页，本页做国家→档位的映射入口
- 10-归因限制配置：分国基准表在彼页，本页做跳转汇总
