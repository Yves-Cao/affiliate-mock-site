# 用户端模拟控制台规范

版本：v0.2
日期：2026-11-08
状态：Active

## 定位

模拟控制台面向产品、研发、测试、风控、财务和其他部门在线验证用户端状态链路。线上 Mock 页面保留右下角「模拟」悬浮按钮，打开右侧抽屉。

所有控制台数据均为虚构仿真数据，标注`Mock演示 · 不代表生产参数`，不得冒充生产规则、生产参数或已审批需求。

## 页签

| 页签 | 能力 |
|---|---|
| 时间 | 显示当前Mock日期，支持+1天、+7天、+30天和1-180天自定义推进；重放后展示资金指标变化摘要 |
| 录入 | 单条录入仿真客户、转化阶段、交易质量、活动、来源和Sub ID；批量录入暂不进入本版 |
| 违规 | 录入违规事件，支持指定既有客户或自动生成SIM客户，由模拟状态机自动联动 |
| 场景 | 正常流、合作清退、Loading、空态、API异常 |
| 数据 | 快照复制、下载、导入，模拟数据统计和二次确认重置 |
| 日志 | 记录时间推进、录入、违规注入、场景切换、导入和重置 |

## 违规自动联动

支持欺诈库命中、重复身份、非新客户、禁推地区、支付拒付、支付异常、虚假流量、品牌词违规竞价、自荐或亲属注册、素材违规和集群风险。

事件写入后自动更新：

1. 客户风险处理状态。
2. 佣金案件状态。
3. 资金三层状态。
4. 客户数据、业绩数据和收益数据。
5. 消息中心通知。
6. 申诉任务。

控制台仅展示原因类别、证据范围、影响范围和下一步，不展示内部评分、权重、阈值或完整证据。

## 数据边界

1. 手动生成对象使用`SIM-`前缀。
2. 邮箱等联系方式始终脱敏。
3. 不录入真实证件、银行卡、税号、生产密钥或生产客户隐私。
4. 快照仅包含模拟日期、录入记录、违规事件、场景和操作日志。
5. 重置只恢复初始Mock日期`2026-10-27`与正常流场景，保留录入、违规和日志，不影响登录状态，便于回看测试过程。

## 用户已确认的范围

1. 使用虚构仿真数据，不录入真实客户隐私。
2. 模拟入口在线显示，方便各部门测试。
3. 本版暂不支持批量录入。
4. 违规事件自动联动客户、佣金、资金、消息和申诉状态。
5. Mock 数据导入、导出、日志和重置均集中在“数据”或“日志”页签内。
