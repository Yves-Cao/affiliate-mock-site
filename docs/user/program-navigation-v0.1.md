# 合作者计划导航抽屉

日期：2026-11-12。状态：用户确认的用户端 Mock 交互，生产服务未接入。

## 页面契约

- 登录成功后统一进入仪表盘；未完成指引时自动显示右侧目录抽屉，背景不加载合作者计划内容。关闭或稍后再看留在仪表盘。
- 已完成指引的用户登录后直接进入仪表盘，不自动弹目录或跳入驻申请；入驻申请继续从既有入口进入。
- 左下角「合作者计划」和指引页「计划目录」打开同一个抽屉。直接访问 `#/apply` 保留原有页面入口。
- 目录六项与原六步同源，只显示步骤、用途、到达状态；不复制佣金表或表单进入抽屉。
- 已到达步骤可回看；未来步骤禁用。继续学习进入最高已到达步骤；完成后可回看全部六步。
- 点击可用步骤，先关闭目录，再进入对应原页面；不会因为打开、关闭或回看目录增加进度。
- 从侧栏打开、关闭目录保持当前页面；点击继续学习才进入上次最高已到达步骤。重新登录恢复进度，不强制进入该步骤页面。
- 指引完成、申请审核、KYC和推广链接资格继续独立；目录不改业务状态。

## 空间与交互

桌面使用右侧约半屏抽屉，最大640px，最小480px；小于768px全屏。标题区、内容区和底部操作区明确分离，内容独立滚动，底部按钮常驻且居左。沿用用户端白底、品牌蓝、字号和间距。列表使用行分隔，避免卡片套卡片。

关闭按钮、遮罩、Escape和「稍后再看」都关闭目录并将焦点返回入口。复用全局抽屉焦点约束；抽屉打开时锁定页面滚动，关闭恢复。重新登录未完成用户仍提示，普通刷新不重复自动弹出。
