# Affiliate 接口文档（设计稿）

版本：v0.2 设计稿｜日期：2026-10-23｜状态：**全部接口为设计草案，无任何实现**
⚠️ 性质声明：Affiliate 系统尚未立项开发（等待批复）。本文档是**接口设计稿**，实质是未来 PRD 的技术附件：①所有字段、路径、触发时机均待评审 ②须与 PRD 一起评审，不单独生效 ③引用的已确认口径以 CFD-D/Q/S 编号为准（底账见待决事项.md 与 MRD）。

## 1. 系统定位与接口总览

Affiliate 是 CPA 归因计佣系统，在数据链路上的位置：

```
推广合作方 → [Affiliate 点击登记] → 客户落地 Max CRM（注册/入金/交易）
                                        ↓ (事件回传)
              Affiliate 归因计佣 ← ─────┘
                                        ↑ (口径标准)
                                     IMC 事件契约
```

| 接口组 | 方向 | 触发时机（MRD 场景） | 优先级 |
| --- | --- | --- | --- |
| IF-A 点击登记 | 合作方端 → Affiliate | 客户点击推广链接（S-001） | P0 |
| IF-B 注册归因 | Max CRM → Affiliate | 客户完成注册（S-002、Q-008 首次归因锁定） | P0 |
| IF-C 转化事实回传 | Max CRM → Affiliate | 入金到账/交易/KYC 完成（S-004/005/006） | P0 |
| IF-D 佣金结果查询 | Max CRM/后台 → Affiliate | 日结对账（Q-007 日结） | P1 |
| IF-E 风控信号交换 | Affiliate ↔ Max CRM | 风控事件、Hold、申诉（风控方案三支柱） | P1 |
| IF-F 归因事件上送 IMC | Affiliate → IMC | 点击/归因事件进统一事件契约 | P1 |

## 2. 接口明细（草案）

### IF-A 点击登记（Affiliate 提供）

- **触发**：客户点击合作方推广链接
- **行为**：Affiliate 记录点击（合作方 ID、点击时间、来源参数、`anonymous_id`/设备标识），按 Q-008 生成首次点击记录，30 天窗口内有效
- **返回**：跳转到落地页（携带 Affiliate 追踪参数）
- **关键口径**：首次点击优先（Q-008①）；无来源不归因（Q-008④）
- **已定口径（CFD-D-011 + CFD-D-012）**：本链接体系是合作方渠道数据的采集入口，与 IMC 旧案建链体系（UTM/广告投放）互不隶属；**链接数据格式采用 CRM 现有推广链接数据格式，CRM 侧重构该功能以契合 UTM/RevShare/CPA 业务（CFD-D-012）**，参数设计仍预留 IMC 事件契约兼容

### IF-B 注册归因（Max CRM → Affiliate）

- **触发**：客户在 CRM 完成注册（对应 IMC 事件 `account_signup`）
- **请求**：`member_id`、注册时间、设备标识（对应 CRM `aff_device/add` 采集的 23 字段中可回传部分）、注册来源参数
- **行为**：Affiliate 按 30 天窗口匹配首次点击，命中则**锁定归属且此后不改**（Q-008③），KYC 回查仅用于去重不改判（Q-010）；无匹配则回传"无来源"
- **已定口径（CFD-D-014）**：用户主体身份互斥——只能归属 IB 推荐或 Affiliate CPA 推荐之一，不能同时转化，**以首触为准**；注册时两条线并存时按首触时间归属，另一条失效
- **幂等**：以 `member_id` 幂等，重复通知忽略
- **失败处理**：通知失败重试（策略待定）；Affiliate 不可用时 CRM 注册流程**不应阻塞**（异步解耦，方式待定 A-IF-05）
- **待评审**：推送 vs 轮询 vs CDC 的选型

**设备归因对接建议（助手提出，待评审，A-IF-02 相关）**：

1. `aff_device/add` 存量 23 字段**一概不动**——其为三方广告投放（AppsFlyer/Google/Meta）旧案设施，按 CFD-D-011"三方渠道保留不开发"维持原样，Affiliate 不增删字段
2. 归因走**同标识匹配**而非字段扩展：IF-A 点击登记时 Affiliate 在落地页采集同一套 Web 标识（`ga_client_id`/`fbp`/`fbclid`），App 端经 AppsFlyer 归因带 `appsflyer_id`；IF-B 注册时 CRM 回传该用户设备档案标识，Affiliate 侧同名匹配——此环节 CRM 零改造
3. 兜底：若匹配方案验证后仍有缺口（如合作方点击 ID 需穿透 App 端），启用 `aff_device/add` 预留的 `identifier_1~10` 自定义位（如 `identifier_1` 存合作方点击 ID），不改表结构
4. 联调前须研发澄清：①23 字段"全部必填"按文档偷懒处理，真实必填集待确认，对接按空值可传设计 ②设备档案与用户的关联时点（Web 注册→App 首启场景）需定义，影响 CFD-D-014 首触比对窗口

### IF-C 转化事实回传（Max CRM → Affiliate）

| 事件 | 对应 CRM 事实 | Affiliate 用途 |
| --- | --- | --- |
| 入金到账 | 资金模块"实际到账"（非申请/支付成功） | FTD 判定（S-004） |
| 有效 FTD | CRM"成功 FTD"事实（判定标准见 IMC 文档）；**"有效性"由 Affiliate 合规校验判定，CRM 不落字段（CFD-D-013）** | 佣金应计前置（S-005） |
| KYC 通过 | `kyc_approved` | 身份去重回查（Q-010） |
| 交易事实 | 开仓/平仓成交 | 达标条件判定（Q-007①入金+交易组合） |
| 冲正 | 交易撤销/退款（IMC `reversed` 状态） | 佣金冲正（Q-007⑤） |

- **统一要求**：金额类事件以 USD 计（对齐 IMC 契约）；幂等键=事实事件 ID；附带 `member_id` 与业务时间
- **待评审**：到账判定的字段来源（A-IF-03）、回传是逐事件还是日批

### IF-D 佣金结果查询（供对账）

日结出账后，供 CRM/财务侧核对：合作方维度佣金明细（应计、动态 Hold 中、已冲正、可提现）。结算周期为日结且不设最低提现限制；动态 Hold 初始 1 天、按账户风险分递增，超过 30 天转冻结并进入人工审核（Q-007，递增映射待评审）。

### IF-E 风控信号交换

- Affiliate → CRM：账户风险分结果对应的限制申请（按风控等级限制，P1 评分机制）
- CRM → Affiliate：撞库/设备集群风控信号（复用 CRM 既有风控能力，A-IF-06 选型）
- 全部处置留痕：原因码、规则版本、证据引用（风控方案"统一决策输出"）

### IF-F 归因事件上送 IMC

按 IMC 事件契约登记并上送 Affiliate 专属事件（事件名待定），字段遵循 §通用字段契约（`event_id`、身份链、`collection_method` 等）。上送不作为计佣依据（计佣以 IF-B/C 事实为准），仅进入统一分析口径。**范围已定（CFD-D-011）：新方案只上送 RevShare 和 CPA（合作方）数据，三方渠道数据不在范围内**；IMC 统计与计佣判定职责分离——统计归 IMC，判定归 Affiliate。

## 3. 已确认业务口径速查（写接口时直接引用）

| 口径 | 内容 | 编号 |
| --- | --- | --- |
| 归因 | 首次点击优先；30 天窗口；注册时锁定不改；无来源不归因 | Q-008 |
| 客户识别 | 主档唯一识别（计佣主键）+ KYC 身份辅助去重 | Q-010 |
| 国家 | CRM 内 KYC 完成的国家地址 | Q-009 |
| 结算 | 日结、不设最低提现；拒付全额冲正不足挂负 | Q-007（2026-10-23） |
| 动态Hold | 初始1天，按账户风险分递增；超过30天转冻结并进入人工审核 | Q-007（2026-10-23）；映射数值待评审 |
| 达标 | 入金+交易组合；达标期限 30~90 天（待评审定值） | Q-007 |
| 渠道边界 | IMC 新方案只做 RevShare/CPA 数据；三方渠道功能保留不开发；Affiliate 链接为合作方数据采集入口，计佣判定权在 Affiliate | CFD-D-011 |
| 有效 FTD | CRM 成功 FTD（标准出自 IMC 文档）× Affiliate 合规校验通过（标准出自 Affiliate 文档）；CRM 不落"有效"字段 | CFD-D-013 |
| 身份互斥 | 用户只能归属 IB 推荐或 Affiliate CPA 推荐之一，不能同时转化，以首触为准 | CFD-D-014 |
