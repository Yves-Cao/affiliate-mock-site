# Affiliate Admin Menu Blueprint

版本：v0.2  
日期：2026-11-08  
状态：Active，用于管理端 Mock 导航和页面评审。  
实现位置：`admin-prototype-data.js` 的 `menuBlueprint`。  
完整页面清单：同文件 `moduleBlueprint`、`routes` 和 `admin-modules` 页签。

## 1. 收敛结论

侧栏从“完整产品清单”收敛为“高频工作入口”：

| 项目 | 旧版 | 当前版 |
|---|---:|---:|
| 侧栏分组 | 10 | 10 |
| 侧栏入口 | 75 | 20 |
| 唯一业务路由 | 6 | 6 |
| 合并后的模块页 | 21 | 21 |
| 旧 URL | 部分入口直达 | 保留兼容 |

侧栏只承担三件事：

1. 进入高频业务对象。
2. 进入高频处理队列。
3. 进入配置、报表和治理主入口。

低频规则、事件类型、风险来源、治理动作和页面视角不再单独占用左侧入口，改由页面内页签、阶段看板、视角切换、详情抽屉、全局搜索和任务队列承载。

## 3. 细分能力的承载规则

1. **同一业务对象的不同视角**：用页内视角切换或 URL `view=`，不新增侧栏项。
2. **同一对象的低频操作**：进入详情抽屉或统一任务队列，不新增独立菜单。
3. **识别事实与人工结论**：风险工作台只呈现事实；案件与合规任务负责人工处理。
4. **配置域**：配置中心保留 14 个页签，默认先展示业务配置版本列表；系统配置作为页内入口，左侧只保留一个配置入口。
5. **版本治理**：版本列表支持查看、编辑、复制和新建；编辑/复制生成新的待审批草稿并保留历史版本，不直接覆盖当前生效版本。
6. **系统配置边界**：系统配置独立成表，保存写入系统配置审计，不生成业务版本。
7. **审计与导出**：全局搜索、顶栏审计和治理区块提供入口，避免把每个治理动作平铺在侧栏。
8. **页面内入口优先**：详情、统计下钻、通知、待办和事件链可以跳转到对应页面，但不反向增加侧栏入口。

## 4. 兼容规则

旧入口不再显示在侧栏，但 URL 继续可访问，用于已有书签、通知、全局搜索和事件链跳转：

| 旧入口 | 兼容目标 |
|---|---|
| `partner-onboarding` / `partner-kyc` / `partner-offboarding` / `partner-notes` | `partner-list/view=...` |
| `client-risk` | `client-list/view=risk` |
| `attribution-exception` | `attribution-links/view=exception` |
| `sub-channel` | `link-list/view=channel` |
| `tax-list` | `statement-list` 的税费视角 |
| `report-funnel` | `report-roi` 的漏斗视角 |

兼容入口不得重新出现在左侧菜单，也不得复制底层数据和页面。

## 5. 交互与视觉约束

1. 继续执行 `DESIGN-ADMIN.md` 和 `00B-管理端页面设计与交互规范`。
2. 母菜单无图标、无箭头；子菜单使用语义图标。
3. 同一时间最多展开一个分组；当前路由所在分组保持展开。
4. 侧栏不显示类似进度条的滚动条；内容超出时内部滚动。
5. 1279px以下收为图标态；图标态仍保留 tooltip 和当前项。
6. 侧栏不使用用户端蓝色体系，继续使用 TradeMaster 暖白画布、深色侧栏和棕金强调色。

## 6. 验收

1. 默认页面显示 10 个分组、20 个子入口。
2. 每个子入口都有真实路由或统一审计入口。
3. 21 个模块页和 26 个业务页签继续可通过页面内入口、全局搜索或兼容 URL 访问。
4. 旧兼容 URL 打开正确页面，不产生重复路由或重复数据。
5. 菜单切换只展开当前分组，页面不出现进度条样式滚动条。
6. 运行 `npm run test:admin-prototype` 后，侧栏、深链、模块页和页面交互回归通过。
