## 当前演示设置

1. 仅提供运营（`operations`）、财务（`finance`）、主管（`risk_supervisor`）、管理员（`system_admin`）四个员工身份。旧身份的浏览器选择和任务负责人映射到对应四人；不再额外展示复核员工。
2. 四个岗位均可修改、保存、发布当前系统配置页参数。
3. 本地`demoPolicy.approvalRequired=false`：新处置校验通过后直接进入执行流程，不生成审批通过或自审记录。旧待审任务核对原因和影响后可继续执行，原审批记录保留并标记取消。
4. 审批页仅查看历史；导出直接生成脱敏文件，保留申请人下载权限、过期时间和操作记录。
5. 必填校验、影响预览、敏感修改二次确认及真实领域执行回执约束继续保留。跳过员工审核不等于把待执行标成已完成或把未知支付结果标成成功。
6. 本节仅约束当前会话维护的管理端本地Mock，不更改生产审批要求或其他会话设置。
