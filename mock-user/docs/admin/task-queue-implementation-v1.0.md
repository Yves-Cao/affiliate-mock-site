## 2. 文件与架构

|文件|本次职责|
|---|---|
|`admin-dev.html`|统一入口及缓存版本|
|`admin-dev.js`|路由/菜单/摘要衔接；任务列表、四页签详情、条件表单、审批冻结包、既有导出中心衔接；风险任务处理入口复用队列|
|`admin-dev.css`|`.tq-*`局部样式、宿主768px适配；不引入另一套导航|
|`admin-prototype-data.js`|`AFF_ADMIN_PROTOTYPE.taskQueue`统一本地服务：查询、权限、草稿、预览、审批、执行模拟、幂等回执、证据、导出及审计|
|`openapi/schemas/task-queue.json`|Mock任务行/详情的结构校验基线，不是完整23端点OpenAPI实现|
|`scripts/task-queue-domain-check.cjs`|领域正负测|
|`scripts/task-queue-check.cjs`|真实浏览器交互、八宽截图及覆盖报告|
|`scripts/admin-prototype-check.cjs`|原管理端广域回归；本次更新路由、菜单和任务摘要相关断言|

数据链：

```text
工作台摘要 / 风险页任务入口 / 任务队列
                  ↓
      AFF_ADMIN_PROTOTYPE.taskQueue
                  ↓
 同一 task_id / version / draft / approval / execution / audit
                  ↓
        审批队列 / 既有导出中心
```

该服务是同步、内存中的本地 fixture 适配器。它没有调用23个目标HTTP端点；4020端口旧Mock Server也没有因此实现该目标契约。刷新页面会重置业务演示状态；列偏好及页容量保留在浏览器，敏感草稿不持久存储。真实用户认证、数据库事务、网络乱序、持久化幂等、支付/CRM调用和邮件投递均需研发接入。

## 4. 评审身份与场景

固定时间：`2026-11-08T12:00:00Z`，页面时区`Asia/Shanghai`，即2026-11-08 20:00:00。87条初始任务：23条类型/目的场景、61条分页数据、3条风险共享任务。TQ-S01至12的具体值由领域测试逐项核对。

|Mock角色|会话身份|重点|
|---|---|---|
|risk|DEMO-RISK-01|默认我的待办；002独立解除方案、004延长来源、各风险子表单|
|risk_supervisor|DEMO-RISK-LEAD|风控审批、分派；本人申请由独立风控复核员处理|
|risk_reviewer|DEMO-RISK-REVIEWER|主管申请的独立风控节点|
|finance|DEMO-FIN-01|005抵扣上限80.00；财务申请禁止本人终审|
|finance_reviewer|DEMO-FIN-02|财务申请的独立终审节点|
|operations|DEMO-OPS-01|归属争议、清退来源跳转|
|compliance|DEMO-COMP-01|敏感导出独立审批；本人导出转风控主管|
|system_admin|DEMO-ADMIN-01|006未知支付仅查询、007重试上限、022已明确失败的Postback|
|audit|DEMO-AUDIT-01|授权范围只读，无任务写按钮|

角色切换是Mock演示器，不是生产登录/IAM。所有姓名、编号、金额、政策版本均为合成评审数据。

### 关键流程

1. risk打开002，保存结论说明与证据、生成影响预览、提交；risk_supervisor通过首节点后仍待审批，finance通过末节点后仅进入待执行。
2. finance打开005，80.01被拒绝；80.00可提交，经风控主管及finance_reviewer审批，申请人不能代终审。
3. risk打开004“证据与处理 → 进入来源案件申请解除”，查看精确结算案件、限制及源版本，填写原因后创建/打开独立settlement_recheck；原004版本、状态及冻结不变。新任务需认领、草稿、预览、串行审批。
4. 020“进入清退步骤”定位既有partner-1003合作方详情的清退页签；本页不复制清退表单。
5. 应用查询、选择可见列后申请导出，compliance核对完整冻结范围后批准，回原申请人的既有导出中心下载。

## 5. 严格复审修正

|问题|修正及验证|
|---|---|
|财务或风控主管本人申请无法完成独立审批|增加不同身份的复核职责；预览与审批共用同一路由；覆盖两种申请人全链|
|导出审批缺范围、跨域审核缺业务上下文|冻结并展示完整导出/处置包，审核不依赖审核人能否进入处理人详情|
|清退跳不存在的路由|真实合作方对象及清退页签深链|
|延长任务缺独立解除入口|可信案件包创建/复用独立任务，校验三元组、限制版本及申诉门禁|
|事件入口误建不可送审解除任务|事件仅允许信号复核；独立解除需可信结算案件，失败不留孤立任务|
|审批意见丢失、拒绝后后续节点仍待办|保存节点意见/时间、写审计，取消后续节点且零执行|
|空人员转办绕退池、无权按钮、关闭结果值错误|领域强校验并区分权限/状态；result使用withdrawn/invalidated|
|浏览器返回覆盖未保存表单|恢复原URL后显示确认，继续编辑保留页签及输入|
|移动尺寸/图标偏离契约|修正64px行、原生图标描边、指标列数、44px触屏和纵向底栏|
|并行风险修改恢复局部假操作|任务入口及处理动作统一进入canonical任务页，不用本地Toast冒充写入|
