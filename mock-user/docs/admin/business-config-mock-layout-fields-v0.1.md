# 业务配置 Mock 页面排版与字段底稿

版本：v0.1  
日期：2026-11-08  
状态：Mock 现状盘点，待字段控制评审  
适用范围：`affiliate-mock-site/admin-dev.html#/admin-config/*`

这份文档只记录当前管理端 Mock 已经实现的业务配置页面结构、菜单、字段和控件，作为下一轮“逐项设置字段控制”的底稿。它不冻结生产业务规则，也不替代业务配置方案、系统配置方案或 API 字段字典。

## 1. 页面总结构

业务配置入口位于“系统设置 → 业务配置”，默认路由为：

```text
#/admin-config/overview
```

页面采用两栏工作区：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部导航 / 面包屑 / 角色切换                                  │
├──────────────┬───────────────────────────────────────────────┤
│ 业务配置左侧  │ 当前页面内容                                  │
│ 菜单          │                                               │
│               │ 总览：首页统计、筛选、配置项列表               │
│               │ 小组页：顶部小菜单、版本列表、配置快照         │
└──────────────┴───────────────────────────────────────────────┘
```

### 1.1 左侧业务配置菜单

左侧菜单固定展示：

| 顺序 | 菜单 | 子菜单数 | 子菜单 |
|---:|---|---:|---|
| 0 | 配置总览 | 1 | 配置总览 |
| 1 | 奖励 | 6 | 价格表、资格档与里程碑、质量服务规则、归属与归因规则、信用等级与权益、（配置总览入口不再重复显示） |
| 2 | 结算 | 4 | 动态结算、D+N与熔断护栏、保证金与税费、国家与主体 |
| 3 | 风控 | 4 | 集群规则、硬规则、风险评分规则、违规规则 |
| 4 | 流程与内容 | 4 | 审批流、规则试算、数据治理规则、官方路径与素材 |

当前逻辑菜单项共 18 个，其中包含 1 个配置总览入口，实际业务配置小分组为 17 个。左侧母菜单不展示每个小分组的字段，只负责切换配置域。

### 1.2 详情页顶部小菜单

进入任一业务配置小分组后，右侧内容顶部显示当前母菜单的小分组 Tab：

- 当前母菜单名称。
- 当前母菜单下的全部小分组按钮。
- 当前小分组高亮。
- 鼠标悬浮显示小分组说明。
- 切换小分组直接切换路由和版本列表。

配置总览首页不显示右侧顶部小菜单，避免首页同时出现两套导航。

### 1.3 小分组页面内容顺序

每个小分组页面固定按以下顺序排版：

1. 页面标题：业务分类 / 配置内容。
2. 页面说明和“新建草稿”按钮。
3. 当前小分组版本列表。
4. 版本列表下方的当前选中版本配置快照。
5. 快照底部的“审批与版本控制”说明。

### 1.4 视觉和响应式

- 使用管理端暖白画布、浅色面板、深色主导航和高密度表格。
- 版本列表使用横向滚动，操作列固定在右侧。
- 配置总览统计卡在桌面端四列、窄屏两列、移动端单列。
- 配置总览筛选器在桌面端横向排列，在移动端改为单列。
- 抽屉使用右侧抽屉；复杂配置快照在抽屉内继续沿用表格/卡片。

## 2. 配置总览首页

### 2.1 页面目标

配置总览是业务配置首页，用来判断每个业务配置项当前使用哪个版本、是否存在定时版本、最近由谁修改。系统配置不进入此页。

### 2.2 顶部操作

| 控件 | 类型 | 当前行为 |
|---|---|---|
| 查看系统配置 | 按钮 | 跳转 `#/admin-system-config/system` |
| 创建配置版本 | 按钮 | 打开配置版本创建弹窗 |

### 2.3 统计卡

| 卡片 | 当前计算口径 | 当前说明 |
|---|---|---|
| 当前生效配置 | 有当前生效版本的配置项数量 | 每个业务配置项保留一个当前版本 |
| 待处理版本 | 草稿、待审批、待生效配置项数量 | 需要继续处理 |
| 生效失败 | 状态为生效失败的配置项数量 | 原生效版本继续保持有效 |
| 本月有变更 | 最后修改时间在当前月份的配置项数量 | 按最后修改时间统计 |

### 2.4 筛选器

| 控件 | 类型 | 字段/状态 | 当前行为 |
|---|---|---|---|
| 搜索配置 | 搜索输入框 | 配置名称、分类、版本号、责任角色 | 输入即筛选 |
| 业务分类 | 单选下拉 | 业务奖励与资格、风控与结算、资金与财务、流程与治理、内容治理 | 改变后立即筛选 |
| 状态 | 单选下拉 | 生效中、草稿、待审批、待生效、生效失败 | 改变后立即筛选 |
| 重置 | 按钮 | 清空三个筛选值 | 恢复全部配置项 |

### 2.5 总览表格

| 列 | 当前显示 | 交互 |
|---|---|---|
| 配置项 | 人话名称、稳定编号 | 查看配置项详情 |
| 业务分类 | 左侧母菜单所属分类 | 只读 |
| 当前使用版本 | 版本号、版本名称 | 点击打开版本只读抽屉 |
| 当前配置参数 | 当前版本参数摘要 | 只读 |
| 定时生效版本 | 版本号，没有则显示 `—` | 点击打开待生效版本只读抽屉 |
| 计划生效时间 | 时间，没有则显示 `-` | 只读 |
| 状态 | 生效中、待审批、待生效、生效失败等标签 | 只读 |
| 最后修改人/时间 | 责任角色和更新时间 | 只读 |
| 操作 | 查看、版本列表 | 查看配置项抽屉或进入对应小组版本列表 |

### 2.6 总览详情抽屉

点击“查看”后打开配置项详情抽屉，当前包含：

| 区块 | 字段 |
|---|---|
| 当前配置 | 当前使用版本、状态、定时生效版本、最后修改时间、当前参数摘要 |
| 配置参数 | 当前配置项参数名称列表 |
| 关联版本 | 最近 5 个版本的版本号、更新时间、名称、状态、变更摘要 |
| 底部操作 | 关闭、查看版本列表、创建回退草稿 |

点击总览中的版本号打开只读版本抽屉，当前包含版本号、状态、生效时间、最后修改、配置快照和关闭按钮，不显示编辑或复制按钮。

## 3. 小分组通用版本列表

每个业务配置小分组都有独立版本列表。当前 Mock 为每个小分组生成：

1. 生效中版本。
2. 待生效版本。
3. 已失效历史版本。
4. 已作废草稿。

### 3.1 版本列表字段

| 列 | 数据类型 | 当前显示 |
|---|---|---|
| 版本号 | 文本 | 配置小组英文编号 + 时间戳 + 两位序号 |
| 版本名称 | 文本 | 版本号下方辅助文本 |
| 状态 | 状态标签 | 生效中、待生效、已失效、已作废 |
| 生效时间 | 日期时间 | 未生效显示 `-` |
| 定时生效时间 | 日期时间 | 非定时版本显示 `-` |
| 创建人/时间 | 文本 + 日期时间 | 创建人和创建时间 |
| 最后修改 | 日期时间 | 最近一次修改时间 |
| 操作 | 下拉菜单 | 只显示一个“操作”按钮 |

### 3.2 操作下拉菜单

当前按照版本状态控制：

| 状态 | 操作 |
|---|---|
| 生效中/已锁定 | 查看、复制、创建回退草稿 |
| 待生效/审批中 | 查看、撤回 |
| 草稿 | 查看、编辑、立即生效、设置定时生效、作废、复制 |
| 已失效 | 查看、复制 |
| 已作废 | 查看、复制 |

生效版本自动锁定，页面不提供原地编辑、覆盖、解锁或直接回退。

### 3.3 版本快照公共字段

每个版本快照底部都有“审批与版本控制”区域，当前显示：

- 审批：需要/不需要。
- 审批人。
- 复核人。
- SLA。
- 生效后自动锁定说明。
- 版本修改必须复制或创建回退草稿的说明。

## 6. 下一轮字段控制清单

后续每个字段至少需要单独确认以下控制属性：

| 控制项 | 说明 |
|---|---|
| 是否显示 | 是否在当前页面展示 |
| 是否可编辑 | 只读、草稿可编辑或角色可编辑 |
| 控件类型 | 输入框、数字输入、比例输入、金额输入、开关、下拉、多选、日期时间、数据表、规则表 |
| 是否必填 | 是否允许空值 |
| 数据类型 | 文本、整数、小数、金额、比例、自然日、枚举、对象数组 |
| 允许范围 | 最小值、最大值、精度、枚举值 |
| 默认/参考值 | 是否只是 Mock 参考值，不能当生产默认值 |
| 字段依赖 | 与其他字段的联动、互斥和必填关系 |
| 版本控制 | 是否跟随小分组版本 |
| 审批要求 | 是否审批、审批人、复核人、审核周期、超时处理 |
| 生效方式 | 即时、定时、下一案件、下一批次或下一事件 |
| 影响范围 | 全局、国家、主体、合作方、客户、佣金案件或结算案件 |
| 审计字段 | 前值、后值、修改人、时间、原因、版本号、TraceId |
| 脱敏规则 | 是否需要敏感字段掩码 |

## 7. 当前发现的结构待确认项

1. 总览是按 12 个配置项展示，左侧却有 18 个业务小分组，需要确认 5 个未独立入总览的小分组归属。
2. 价格表、质量服务、动态结算、D+N 和风险规则目前已经有具体字段；集群规则、硬规则、违规规则仍使用通用规则表，需要分别下钻。
3. 当前版本快照统一展示审批人、复核人和 SLA，但每个风险规则是否可以独立设置这些字段，需要单独确认。
4. 当前总览的当前版本来自全局版本事实源，小分组页同时展示独立小组版本，需要确认最终是否保留两种版本编号。
5. 当前 Mock 中的示例值均为演示数据或参考值，下一轮字段控制时需要逐项标记“已确认、参考值、待评审或仅 Mock”。
