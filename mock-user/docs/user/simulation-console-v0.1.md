# 用户端模拟控制台规范

版本：v0.3
日期：2026-11-11
状态：Active

## 定位

模拟控制台面向产品、研发、测试、风控、财务和其他部门在线验证用户端状态链路。线上 Mock 页面保留右下角「模拟」悬浮按钮，打开右侧抽屉。

所有控制台数据均为虚构仿真数据，标注`Mock演示 · 不代表生产参数`，不得冒充生产规则、生产参数或已审批需求。

## 页签

| 页签 | 能力 |
|---|---|
| 时间 | 显示当前Mock日期，支持+1天、+7天、+30天和1-180天自定义推进；重放后展示资金指标变化摘要；可记录每日结算前后快照 |
| 录入 | 单条录入仿真客户、转化阶段、交易质量、活动、来源、国家和Sub ID；国家和Sub ID优先使用系统选项；批量录入暂不进入本版 |
| 违规 | 录入违规事件，支持指定既有客户或自动生成SIM客户，由模拟状态机自动联动 |
| 信用 | 手动调整VIP等级和演示积分，仅用于展示权益和进度变化 |
| 场景 | 业务状态（正常链路、合作清退）和页面状态（加载中、空态、API异常）分组展示；切换场景不清除仿真数据，并显示检查点 |
| 数据 | 快照复制、下载、导入预览与校验、对象数量、单条仿真对象清理，以及三种重置模式 |
| 日志 | 记录时间推进、Mock日期、录入、违规注入、场景切换、结算快照、导入和重置 |

## 违规自动联动

支持欺诈库命中、重复身份、非新客户、禁推地区、支付拒付、支付异常、虚假流量、品牌词违规竞价、自荐或亲属注册、素材违规和集群风险。

事件写入后自动更新：

1. 客户风险处理状态。
2. 佣金案件状态。
3. 资金三层状态。
4. 客户数据、业绩数据和收益数据。
5. 消息中心通知。
6. 申诉任务。

控制台仅展示原因类别、证据范围、影响范围和下一步，不展示内部评分、权重、阈值或完整证据。

## 数据边界

1. 手动生成对象使用`SIM-`前缀。
2. 邮箱等联系方式始终脱敏。
3. 不录入真实证件、银行卡、税号、生产密钥或生产客户隐私。
4. 快照包含模拟日期、录入记录、违规事件、信用覆盖、结算运行快照、场景和操作日志；导入前校验版本、有效日期、数组成员、重复编号、数值和时间推进摘要，校验失败不覆盖原数据。
5. “重置展示环境”恢复初始Mock日期`2026-10-27`、正常链路和基线信用，清除结算运行快照，保留录入、违规和日志。晚于当前Mock日期的客户及违规保留在模拟数据中，到对应日期才参与页面与通知重放。
6. “清空仿真数据”删除本次录入和违规，保留日志；“恢复初始演示包”同时清除历史日志。
7. 每日自动结算按钮记录当前日期的结算快照，不创建提现记录、不直接打款；余额变化由Mock日期推进后的数据重算产生。
8. 结算快照和场景以模拟状态为唯一来源；刷新、导入和三种重置后同步页面投影。结算快照同一Mock日期只记录一次，点击后立即持久化。
9. 单条删除客户同步清除其模拟违规；删除后再次录入不得与仍保留的客户、事件或日志编号冲突。
10. 场景切换即时更新页面；页面上的“恢复正常流”同时更新模拟控制台状态。API异常的重试仍保留错误，不伪造接口恢复。

## 用户已确认的范围

1. 使用虚构仿真数据，不录入真实客户隐私。
2. 模拟入口在线显示，方便各部门测试。
3. 本版暂不支持批量录入。
4. 违规事件自动联动客户、佣金、资金、消息和申诉状态。
5. Mock 数据导入、导出、日志和重置均集中在“数据”或“日志”页签内。
6. 场景切换与数据清理分开，避免把展示状态误认为完整数据恢复。
