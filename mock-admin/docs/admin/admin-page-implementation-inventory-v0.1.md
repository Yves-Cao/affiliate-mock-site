## 2. 全局框架

### 2.1 页面骨架

```text
深色侧栏
└ 品牌
└ 工作空间身份
└ 10组高频菜单，单分组展开
└ 版本

主区
└ 顶栏：面包屑、时间、延迟、搜索、通知、权限、审计、账号
└ 已打开页签条
└ 页面标题 + 描述 + 主操作
└ 页面主体
└ 页脚：产品、数据源、更新时间
```

### 2.2 侧栏菜单

1. 母菜单只做分组标题，无箭头、无图标。
2. 默认只展开当前路由所在分组。
3. 点击新分组时收起上一个分组。
4. 子菜单有语义图标、缩进和连接线。
5. 子菜单右侧显示 `MVP / P1 / P2`。
6. 1279px以下收为图标态。
7. 侧栏滚动条隐藏。
8. 低频规则、事件、治理动作和视角通过页面内页签、阶段看板、详情抽屉、任务队列、全局搜索和兼容URL访问，不再单独占用侧栏。

### 2.3 顶栏

| 组件 | 内容 | 行为 |
|---|---|---|
| 面包屑 | `Affiliate Ops / 分组 / 页面` | 显示当前位置 |
| 时间 | 系统时间、本地时间 | 常驻 |
| 延迟 | API延迟状态 | 常驻 |
| 全局搜索 | `Ctrl/Cmd + K` | 打开搜索抽屉 |
| 通知 | 未读数 | 打开通知抽屉 |
| 权限 | 当前页面权限 | 打开权限抽屉 |
| 审计 | 全局审计 | 打开审计抽屉 |
| 账号 | 当前角色缩写 | 显示当前身份 |

### 3.4 标准筛选器

所有表格页默认提供：

1. 关键词：ID、名称、对象、TraceId。
2. 状态筛选。
3. 风险筛选。
4. 责任角色筛选。
5. 开始日期。
6. 结束日期。
7. 查询、重置。
8. 保存视图。
9. 列设置。
10. 刷新。
11. 异步导出。

### 3.5 标准表格

1. 固定选择列。
2. 固定操作列。
3. 表头排序。
4. 分页。
5. 每页20/50/100条。
6. 数字、金额、时间使用tabular nums。
7. 长文本省略，详情抽屉显示全文。
8. Loading保留表头。
9. Empty提供下一步。
10. Error显示错误码、原因、TraceId。

### 3.6 页面交互收口

v0.34移除了全页面统一叠加的“深度交互工作台”。该区域曾重复呈现阶段板、快捷筛选、对象检查器和依赖动作，增加页面高度并干扰主流程。当前页面按业务对象承载交互：

1. 页面专属阶段看板只出现在确有生命周期语义的页面，并直接联动当前表格。
2. 页面筛选、保存视图、排序、列设置和分页保留在统一列表工具栏。
3. 对象完整上下文通过业务详情抽屉、事件链抽屉、风险案件抽屉或报表下钻提供。
4. 行内动作按对象状态和角色权限显示；复杂动作使用业务弹窗并写入审计。
5. 业务路径和依赖仅在对应详情抽屉中展示，不再在所有页面重复铺开。

动作回写能力：

| 动作 | 回写结果 |
|---|---|
| 新建草稿 | 创建新对象并进入表格 |
| 认领 | 状态改为处理中 |
| 转办 | 状态改为待处理并更新处理人 |
| 补充材料 | 状态改为待补充 |
| 提交审批 | 状态改为待审批 |
| 审批 | 状态改为已通过或拒绝 |
| 生成复核 | 状态改为待复核 |
| 生成建议 | 写入建议任务 |
| 异步导出 | 写入导出中心任务 |

每个动作写入对象时间线、全局审计、操作人、TraceId、self_review标记和动态执行参数；这些能力不依赖统一工作台。

## 14. 横向组件

### 14.1 全局搜索

1. `Ctrl/Cmd + K`打开。
2. 搜索业务对象、配置发布包、风险案件、报表维度、集成系统、事件缺口、集成任务、导出任务、审计。
3. 支持多关键词、类型筛选、最近搜索、角色可见范围。
4. 支持ArrowDown和Enter键盘操作。

### 14.2 通知中心

1. 顶栏未读数。
2. 审批超时、集成失败、风险告警、导出、签核提醒。
3. 单条已读、全部已读、来源跳转。

### 14.3 权限可见性

1. 当前角色。
2. 搜索可见范围。
3. 数据范围。
4. 可执行和不可执行动作。
5. 脱敏字段、隐藏字段、导出边界。

### 14.4 配置发布抽屉

1. 发布状态。
2. 组合差异。
3. 组合试算。
4. 签核状态。
5. 发布时间线。
6. 签核、定时、生效、回滚、恢复。

### 14.5 风险案件抽屉

1. 案件状态。
2. SVG关系图。
3. 成员与逐案资金。
4. 调查SLA。
5. 统一隔离队列。
6. 处理时间线。
7. 拆分、升级、组结论、解除隔离。

### 14.6 报表维度抽屉

1. 维度指标。
2. 客户、佣金、风险案件下钻。
3. 建议口径。
4. 生成建议。

### 14.7 集成系统抽屉

1. 系统状态、延迟、成功率、积压、重试率、回调失败率。
2. 依赖链路。
3. 健康时间线。
4. 重新检查。

### 14.8 动作弹窗

1. 影响预览。
2. 原因输入。
3. 自动审核提示。
4. 权限校验。
5. 审计写入。
6. 结果反馈。

## 16. 验收检查

每页上线前必须确认：

1. 路由可直达。
2. 菜单分组自动展开。
3. 页面标题、描述、主操作正确。
4. 8个统计口径正确。
5. 筛选器可用且保存视图有效。
6. 表格排序、分页、列设置有效。
7. 详情抽屉包含基础信息、影响关联、业务路径、对象360、审计。
8. 主操作按模块语义显示。
9. 操作受角色权限控制。
10. 写操作记录原因和审计。

12. 1440、1279、390宽度无横向溢出。
