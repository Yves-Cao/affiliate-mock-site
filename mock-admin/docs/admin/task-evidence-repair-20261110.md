# 仪表盘任务证据详情修复记录

日期：2026-11-10。范围：管理端本地Mock及对应页面/接口文档；未接入生产证据库或外部附件。

## 原问题与修复

从仪表盘任务行进入任务，再点击“证据与处理 → 预览”，所有任务都返回同一段占位文字。现已按当前任务返回来源核验快照，展示证据身份、来源/快照版本、采集时间、业务摘要、客户/合作方及佣金/结算案件明细、类型专用业务依据。下载同一条证据的纯文本快照。

弹窗宽880px，受视口约束；固定标题/底栏、中部滚动，明细表内部横滚。正文可键盘聚焦及PageDown滚动；查看证据期间暂停列表/详情自动替换，避免丢失阅读位置。关闭返回原任务和页签。

证据内容按领域授权；可看任务的管理员不能因此查看风险全文。访问检查用途、归属、版本、权限、扫描及有效状态，下载重新校验。预览/下载留审计；正文不进入持久化幂等缓存及回执。空材料、缺失及无权状态不使用其他任务内容兜底。未提供的哈希不伪造。

本地快照源于已有任务字段与案件引用，不能当作银行凭证、真实外部文件或CRM新增事实。生产HTTP仍按既有授权内容服务契约接入。
