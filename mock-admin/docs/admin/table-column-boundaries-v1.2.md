# 管理端数据表列边界 C-B02 v1.2

日期：2026-11-09。依据：用户要求每列值不得覆盖相邻列；产品侧登记在`Affiliate管理端组件规范-v1.1.md`第7节及`DESIGN-ADMIN.md`。

## 实现

- `admin-table.css`统一表头和单元格裁切、控件宽度、单行徽章省略、操作组换行、表内容器滚动。
- `admin-table.js`为无`colgroup`的表格初始化最小宽度，已有表头像素宽度优先，未定义列128px、操作列160px。已有表格最小像素宽度保留；调整列宽的表格继续使用原`colgroup`。
- 辅助脚本为单元格和常用内容节点补完整`title`，通过批量MutationObserver处理动态渲染和文本更新，保留已有复制说明和禁用原因。
- 四个现有管理端HTML入口加载同一共享文件，使用`body.admin-tables`隔离；挂载在`body`的抽屉和弹窗也适用。
- 客服标题仍最多两行；客服和任务徽章继续换行。固定列和业务动作逻辑沿用现有实现，列宽热区收回表头内部。配置菜单继续使用已有body浮层。
- 合作方360表格宿主网格允许收缩；窄屏顶栏允许收缩，避免文档横向滚动。
