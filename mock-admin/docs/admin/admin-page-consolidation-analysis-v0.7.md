## 1. 组1 仪表盘（4入口→1页）

**✅决议（2026-11-06用户拍板）：采纳统一驾驶舱。**

**✅组1组件决议（2026-11-06第二轮拍板，6项全采纳）：**

1. 视角切换器：驾驶舱头部右侧四段式（任务/经营/风险/资金），与角色标签同排；切视角不改路由。
2. 角色默认视角（保守映射）：运营→任务；风控/风控主管→风险；财务→资金；合规/系统管理员/审计→任务；经营无默认角色，手动切或菜单别名进入。
3. 四视角指标集（每视角4项大数字+环比箭头）：任务=我的任务/待处理/今日超时/待审批；经营=今日点击/有效FTD转化/今日计佣/净ROI趋势；风险=高风险对象数/活跃案件组/隔离佣金总额/SLA超时数；资金=今日Hold到期/保证金覆盖率/提现失败笔数/冲正在途金额。角色专属指标保留在任务视角。
4. 待处理表：8行、列不变；排序权重按视角切换（任务=超时×金额；风险=SLA剩余×风险等级×隔离金额；资金=金额×紧急度；经营=综合影响力）。
5. 菜单别名与路由清理：三个总览菜单入口→进驾驶舱预设视角（带view参数）；撤销dash-operation/dash-risk/dash-funds三个模块路由；蓝图菜单同步升版登记。
6. 数据统计区：随视角切换指标分布（任务分布/经营漏斗分布/风险分布/资金分布）。

**结论：四总览合并为统一角色驾驶舱**（`#/admin-workbench/tasks` 既有路由，结构已锁：总结面板→待处理表→统计→队列）。

1. 三个P1总览页（经营/风险/资金）结构与报表页同模板，是v26同质化典型样本；全部数据是下游页面的计数投影，无自有对象。
2. 合并形态：驾驶舱顶部加视角切换器（任务/经营/风险/资金），切换只改指标集、异常信号、待办排序权重，不复制页面。菜单别名保留，进入预设视角（如`?view=risk`），默认视角跟随登录角色（风控主管→风险视角）。
3. 边界铁律：驾驶舱只放「数字+环比+异常信号+TopN跳转」，趋势图和多维下钻归报表组；数据源健康度已移出，归集成任务页。
4. 与组7「全部任务」是同页跨组别名，权限矩阵按页面登记不按菜单重复计。

## 5. 组5 佣金与资金（8入口→7页，主方案）

**✅决议（2026-11-06用户拍板）：选主方案——「结算与税费」合并执行，提现/冲正/对账独立保留；资金中心激进方案不采用。**

硬约束：Hold管理、保证金管理为既有契约页签不动。

1. **结算单+税费管理→「结算与税费」**（强推荐）：税费作页签；招牌组件=扣减瀑布（佣金合计→税费→保证金→净额）。理由：MVP仅USD无多币种复杂度；税单后置内容薄；代扣记录与结算明细同源，分页即「数据详情一模一样」。

3. **备选激进方案**：结算与税费+提现+冲正与追回+对账→「资金中心」一页四页签+资金管道总览（8入口→4页面）。优点：减页彻底、资金链路心智集中；代价：单页信息密度高。用户减页意愿强时采用。
