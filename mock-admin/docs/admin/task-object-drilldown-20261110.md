# 任务受影响对象与360资料下钻

日期：2026-11-10  
状态：本地实现、针对性回归与浏览器走查通过，页面文档已同步。本文不作为CRM、生产HTTP、IAM或全页验收完成证明。

## 范围与页面依据

本轮只完善统一管理端Mock中“任务 → 受影响客户/合作方 → 全页360 → 返回任务”的资料核对流程，不修改用户端、生产业务规则、审批策略或API契约。

- [任务队列页面42](../../../Affiliate/原型/页面规范/42-管理端-任务队列-v1.0.md)：受影响对象、精确身份、360下钻与TQ-OBJ01~05。
- [客户360页面43](../../../Affiliate/原型/页面规范/43-管理端-客户360.md)：任务来源、只读资料核对和返回恢复。
- [合作方360页面46](../../../Affiliate/原型/页面规范/46-管理端-合作方360.md)：任务来源、跨客户查看和P360-TASK-01~03。

## 目标交互

1. 任务“概览”和“证据与处理”均显示同一份受影响对象清单。
2. 客户/合作方从直接引用、`case_refs`、`members`、聚合`customer_ids`及来源风险事件的授权关联中整理，按对象类型和完整ID去重，保留关联案件。
3. 点击对象进入统一Mock全页客户360或合作方360；可查看其授权脱敏资料、归属/客户关联、资金案件、风险事件和关联任务历史。
4. 可由客户进入关联合作方，或由合作方进入关联客户；“返回任务”恢复最初任务。
5. 同会话恢复任务详情页签、未保存表单/检查项/证据选择，以及任务列表查询、排序、分页和滚动位置。未保存内容不写入URL或持久存储，刷新后的恢复仍依赖已保存草稿。

## 数据与边界

- 使用完整精确ID；`DEMO-C1`与`client-2001`不因后缀相同而合并或互相替代。
- 当前本地可为任务已有引用提供同ID合成资料，并关联同ID已有案件、风险事件及任务历史；不是外部CRM原始记录或生产HTTP响应。
- 未知/越权对象显示安全提示和返回入口，不兜底显示其他对象。
- 无来源字段显示“未提供”，不伪造已完成KYC/KYB、已同步或资金执行结果。邮箱、手机号保持脱敏。
- 对象清单只用于核对资料，不扩大当前客户+佣金案件+结算案件三元组的处置或冻结范围。
- 四个员工身份和演示跳过审核的既有策略保持不变；查看资料不生成审批通过或领域执行回执。

## 本地实现接口

`AFF_ADMIN_PROTOTYPE.taskQueue.affectedObjects(taskId, context)`返回授权受影响对象清单；`reviewObject(taskId, type, id, context)`返回同ID的资料、关联客户、案件、风险事件、任务及历史。它们是本地投影方法，不是新增的生产HTTP接口。

客户页包含概览、归属与转化、佣金与结算、风险与关联、事件时间线；合作者页包含概览、客户与推广、合规与资料、财务与结算、风险与信用、跟进与审计。案件详情在表格下方展开，不挤入窄操作列。其他关联案件与本次任务范围分别标记，查看不扩大处置范围。
