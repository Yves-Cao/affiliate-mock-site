## 已闭环

| 能力 | 当前状态 |
|---|---|
| 20个用户端路由 | 已覆盖仪表盘、数据、推广、资金、服务、入驻流程 |
| Figma视觉基线 | 颜色、核心字号、表格、抽屉、状态标签已统一 |
| 资金链路解释 | 收益、提现、钱包共享资金可用性组件；金额同源并标明账户全量口径 |
| 客户与业绩下钻 | 报表指标可进入已筛选客户数据并回到第一页 |
| 导出中心 | 支持生成、下载、失败重试、过期状态和审计提示 |
| 支持工单 | 支持创建、详情、补充、关闭、SLA与消息中心联动 |
| 账户与合规 | 支持概览、资料认证、协议留痕、财务税务、安全通知 |
| 财务税务在线变更 | 支持脱敏变更申请、复核状态、审计编号和消息中心通知 |
| 合作清退 | 隐藏`closure-flow`场景覆盖链接下线、活动/二级渠道/深度链接/素材暂停、新提现暂停、最终结算阶段、保证金与申诉链路 |
| Loading/Error状态 | 隐藏`loading-flow`提供稳定骨架屏；`api-error`提供错误码、traceId和重试 |
| 模拟控制台 | 在线可见右下角入口；支持时间重放、单条仿真客户录入、违规自动联动、场景、快照、导入、日志和环境重置；重置保留仿真客户、违规事件与日志 |
