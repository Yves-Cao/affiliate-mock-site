# 04 注册归因泳道图绘制说明

图示预览：[Mermaid注册归因泳道图](04-注册归因泳道图-Mermaid预览.md)。

版本：v0.1。状态：文字资料已整理，待绘制及CRM/技术评审。  
用途：明确从官方链接点击到最终客户归属锁定的事实保存、规则判断、异常补偿和审计。

## 1. 范围和边界

起点为客户访问官方推广链接，终点为归属锁定或有原因的无来源、排除、待核验。客户注册与认证在CRM完成；最终Affiliate归属由Affiliate判断。图中“数据库直连”不意味着任意修改CRM原表。

## 2. 泳道与节点

| 编号 | 泳道 | 节点与输出 |
| --- | --- | --- |
| A01 | 合作者 | 分享官方域名及官方路径推广链接 |
| A02 | 客户/追踪入口 | 点击，记录点击ID、链接ID、时间和参数 |
| A03 | CRM | 接收注册并生成注册ID、客户ID |
| A04 | CRM | 保存原始查询快照、点击序列、UTM、活动、二级渠道和自定义参数 |
| A05 | CRM | 提供候选归因、客户归属与记录版本 |
| A06 | Affiliate | 读取受控表/视图，检查数据完整性和新鲜度 |
| A07 | Affiliate | 校验官方入口、链接及点击有效性、归因窗口 |
| A08 | Affiliate | 校验唯一客户、已有Affiliate归属和IB归属 |
| A09 | Affiliate | 按首次有效点击优先规则确定候选；缺点击时检查推广码兜底资格 |
| A10 | Affiliate | 保存最终归属、锁定时间、来源和规则版本 |
| A11 | 任务/人工核验 | 补数、冲突调查或禁止归属复核 |
| A12 | 事件/IMC | 发布并消费归因结果事件 |

## 3. 正常连接

| 起点 | 终点 | 触发条件及结果 |
| --- | --- | --- |
| A01 | A02 | 客户访问；非合作者自有域名 |
| A02 | A03 | 客户发起CRM注册 |
| A03 | A04 | 注册事实与原始参数关联，原件保留 |
| A04 | A05 | 点击序列和候选归因可查询 |
| A05 | A06 | 数据版本和权限满足读取契约 |
| A06 | A07 | 关键事实齐备且无同步冲突 |
| A07 | A08 | 点击有效且未被禁止使用 |
| A08 | A09 | 不存在排斥性的历史归属 |
| A09 | A10 | 存在符合规则的确定来源 |
| A10 | A12 | 归属与事件持久化结果可关联 |
| A10 | 后续资格计佣 | 使用锁定归属及后续CRM事实 |

## 4. 决策分支

| 判断节点 | 条件 | 应连向的结果 |
| --- | --- | --- |
| A06 | CRM缺数、延迟或版本冲突 | A11待同步/冲突任务；不猜测归属 |
| A07 | 非官方入口、点击失效或已确认高风险点击 | 排除有效点击及该点击归因，记录原因 |
| A08 | 已有IB归属 | 排除Affiliate归属，不生成该客户CPA佣金 |
| A08 | 同一客户已有有效Affiliate归属 | 幂等返回原结果或冲突核验，不新增双重归属 |
| A09 | 有多次有效点击 | 保留序列，按首次有效点击优先 |
| A09 | 点击缺失而推广码符合兜底规则 | 记录兜底来源及原因后继续锁定 |
| A09 | 无有效来源且无可用兜底 | 无来源，不用国家、IP或设备猜测归属 |
| A10 | 锁定后再次点击 | 记录后续点击，不自动改判既有归属 |

一般集群疑似与已确认禁止使用的风险点击要分开：前者进入后续风险结算控制，不把“佣金照算”的原则误用于根本不存在合法归属的情况。

## 5. 补偿与人工变更

1. 缺数任务关联注册、客户和来源版本，补数后从A06重新校验。
2. 重复通知或重复读取返回同一归属结果，不重复建账。
3. 冲突核验保留CRM原始事实；历史结论调整必须有依据、权限、审计及下游影响核对。
4. 事实修正不等于立即重算或改写已支付金额，涉及计佣资金时转对应重算/冲正流程。
5. 不画一个“人工修改归属”按钮直接覆盖CRM原始参数或已锁定历史。

## 6. 数据标注

| 数据组 | 图旁标注 |
| --- | --- |
| 原始事实 | `registration_id`、`customer_id`、注册时间、`raw_query_snapshot`、`record_version` |
| 触点 | `click_id`、`link_id`、首触/末触时间、点击序列、来源域名及路径 |
| 渠道 | `activity_id`、`campaign_id`、`sub_id`、UTM、自定义归因参数 |
| 最终归属 | `attribution_id`、`partner_id`、方法、锁定时间、规则版本、IB排除结果 |
| 审计补偿 | 原因码、任务ID、操作人、证据引用、`trace_id` |

## 8. 绘图核对

原始参数与标准化归属分开；多次点击有序列；有IB排除；无来源不猜测；锁定后不自动改判；CRM回传明确待评审。
