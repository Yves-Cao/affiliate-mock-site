# 03 端到端业务泳道图绘制说明

图示预览：[Mermaid端到端业务泳道图](03-端到端业务泳道图-Mermaid预览.md)，采用最新入驻及审批决策；旧文字差异见预览来源与待核验说明。

版本：v0.1。状态：文字资料已整理，待绘制和专业评审。  
用途：明确从入驻获客到实际打款、风险追索的跨岗位和跨系统责任，不将泳道名称当成必须独立部署的服务。

## 1. 起点、终点与范围

起点为合作者申请加入CPA计划；正常终点为提现对账完成，异常终点为有证据的拒绝、冻结、待补偿或追索。质量服务、保证金释放及付款后异常是独立支线。

## 2. 泳道

| 泳道 | 责任 |
| --- | --- |
| 合作者 | 入驻、推广、自助查询、手动提现、申诉和工单 |
| 被推荐客户 | 官方入口访问、CRM注册、认证、入金及交易 |
| Affiliate | 计划状态、归属、资格、计佣、结算、资金记录、任务和事件 |
| CRM | 账户资料与认证、注册客户及行为事实、实际打款与外部支付事实 |
| 运营/风控 | 业务受理、调查、证据与风险处置申请、复核 |
| 财务 | 敏感资金审批、差异复核、冲正抵扣和对账 |
| 支付/银行 | 接受CRM指令、执行外部支付、返回渠道结果 |
| IMC | 消费事件做分析，不决定归因、计佣或付款 |

## 3. 正常流程节点

| 编号 | 所属泳道 | 节点与输出 |
| --- | --- | --- |
| E01 | 合作者/CRM | 使用CRM账户与资料，发起计划入驻 |
| E02 | 运营/Affiliate | 入驻审核通过，合作计划状态允许推广 |
| E03 | Affiliate/合作者 | 官方推广链接可用，合作者投放 |
| E04 | 客户/CRM | 点击并注册，保存点击、参数和客户事实 |
| E05 | Affiliate | 有效性、唯一性、IB隔离检查后锁定归属 |
| E06 | CRM | 持续提供认证、资金及交易事实 |
| E07 | Affiliate | 记录FTD里程碑，不产生可放款资金 |
| E08 | Affiliate | 有效FTD确认，计算基础CPA及前两环节附加 |
| E09 | Affiliate | 独立佣金案件进入动态结算中，保存快照 |
| E10 | Affiliate/风控 | 实名门槛核验、风险检测、结算前检查及超时保护 |
| E11 | Affiliate | 每日凌晨自动结算，税费与保证金处理，余额入账 |
| E12 | 合作者/Affiliate | 手动提现，创建订单和FIFO分摊快照，不生成月度结算单 |

| E15 | CRM/支付银行 | 执行支付并回传处理结果 |

## 4. 必须绘制的跨泳道交接

| 起点 | 终点 | 连接条件或载荷 |
| --- | --- | --- |
| E01 | E02 | 申请和资料引用齐备 |
| E02 | E03 | 计划状态允许；不是本地另建CRM认证 |
| E03 | E04 | 官方链接、点击ID、活动及二级渠道参数 |
| E04 | E05 | CRM事实及版本可读 |
| E05 | E06 | 归属已锁定并关联客户ID |
| E06 | E07、E08 | 资金交易事实满足各自规则 |
| E08 | E09 | 幂等生成案件与金额明细 |
| E09 | E10 | 每案独立，基础CPA不等质量服务 |
| E10 | E11 | 到期、数据完整且无有效阻断 |
| E11 | E12 | 有可用余额且合作者主动申请 |
| E12 | E13 | 订单与结算单一对一，防重复占用 |
| E13 | E14 | 全部必要审批及执行检查通过 |
| E14 | E15 | CRM受理，Affiliate不绕过CRM支付 |
| E15 | E16 | 回执或主动查询核验结果 |
| E05、E08、E16 | IMC | 已提交领域事件经可靠投递消费 |

## 5. 异常和恢复支线

- E04/E05缺数：创建集成任务；补数后重跑校验，不能猜测归属。
- E05禁止归属或无有效来源：不进入CPA计佣；记录排除原因。
- E10集群、调查、隔离或关键缺数：继续计佣，阻断自动结算并生成任务。
- E10合作者未实名：提示去CRM完成实名，未实名不得自动或人工结算；采用待决事项第1A.15节实名门槛结论。
- E10超时：只冻结当前案件三元组；信号、调查、申诉与资金状态分别维护。
- E13驳回：记录原因，按允许状态处理占用；不得绕过审批付款。
- E14/E15未知：先查询CRM，不重复发起可能已成功的付款。
- E15部分成功：保留成功部分，确认未成功部分才回余额。
- E16后拒付或欺诈：形成冲正案件，审批后按固定顺序抵扣及追索。

## 6. 独立支线

质量服务达成后另建佣金案件，重新经过E09至E11，不阻塞基础CPA。保证金逐案到期，无风险部分进入余额，关联未结风险部分继续冻结。

## 7. 数据和审计锚点

链路关联`partner_id`、`customer_id`、`attribution_id`、`commission_case_id`、`settlement_case_id`、`withdrawal_id`、`statement_id`、`crm_payout_id`和`trace_id`。敏感操作记录申请、审批、执行人及原状态/新状态；不能用任务关闭替代资金放行。

## 9. 绘图核对

没有CRM事实直接跳到银行的连接；自动结算不生成人工提现；IMC没有回流到计佣前置；每条异常有责任泳道和恢复条件。
