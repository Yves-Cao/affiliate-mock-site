版本：v0.4  
更新日期：2026-11-12。  
状态：20类基础图示及7类CRM专项文字图稿、Drawio XML和独立HTML预览已形成；待内容审阅和相应专业评审。  
用途：为内部评审提供可编辑的Markdown图稿及来源，支持继续在其他软件中制作图示。

## 1. 本目录如何使用

本目录保留20个基础主题，并增加7个CRM专项图稿。每份文档说明该图应回答的问题、参与角色、节点、连接条件、异常恢复、数据与审计锚点和资料来源。复杂主题可以拆成多张图，不要求每个主题各挤进一张图。

这些文档是现有业务资料的绘图表达，不建立第二套业务规则；未解决的规则冲突继续由原专题和[待决事项](../待决事项.md)承接。用户在绘图前可以直接修改本目录文字；如果涉及业务决定变化，需同步原正文及相关契约，不能仅改图中文字。

本目录最初交付20类文字文档。按用户后续要求，01提供[项目全景图Mermaid预览](01-项目全景图-Mermaid预览.md)，本批完成02至20共19份Mermaid预览、46个图块。各主题均保留文字绘制说明，预览用于审阅内容与关系；不确定的分支标为待决或待核验，并引用原议题。未修改原型。

查看时打开下表的“Mermaid预览”，在支持Mermaid的Markdown工具中渲染。编辑相应文件内的`mermaid`代码块即可调整图中文字和连线；文字说明仍用于追溯规则、异常和绘制要求。图稿是对来源的表达，不替代原正文。

为便于集中查看，另提供[流程图静态目录](静态页面/00.html)。每个流程图都是独立HTML页面，左侧导航使用普通页面链接直接跳转，01先展示Drawio XML并保留其Mermaid预览，其余主题渲染Markdown中的Mermaid源码；该HTML为离线预览，不替代Markdown正文和业务评审。原`流程图导航.html`保留为兼容入口，并自动转到静态目录。

2026-11-11首轮AI整改更新了01、03、07的提现说明；其中旧Drawio和静态导出若仍展示提现生成月单、全额归集或全人工审批，只作历史参考。以当前主PRD和下表链接的最新文字源稿为准。

2026-11-12补齐08风险处置、09风险传播，均为v0.2：08拆为五张子图，09拆为四张子图，文字、Mermaid、Drawio XML多页与HTML同步。旧版8份原件保留在[风控图版本留档](../../归档/风控流程图-2026-11-12/README.md)。HTML提供放大、缩小及适应宽度；手机端可从“流程图导航”返回目录。

## 3. 建议绘制顺序与版式

1. 先绘01、12、21，让参与者理解项目、系统边界和CRM责任边界。
2. 再绘22、23、04，确认入驻、注册、归因和CRM事实交接。
3. 再绘24、05、06、07、25，确认客户事实、计佣、结算、提现和打款。
4. 绘26、27、08、09、10、11、19，检查异常补偿、回传、风险、状态、配置和授权。
5. 绘13至18，供研发、CRM团队和测试核对技术与数据契约；用02和20检查服务交接与研发门禁。

全景图和逻辑架构图优先从上到下分层排列，层数由业务内容决定，不固定为四层。泳道图按参与者分道，时间顺序统一；时序图保留参与者列与时间轴；ER和权限矩阵采用适合关系比较的形式。

分层标题与节点留独立空间，箭头连接节点边缘，长跨层关系用编号或连接点。异常和恢复在侧边展开，不跨过标题。需要拆图时，用共同对象编号和主从图编号保持对应。

## 4. 统一业务口径

| 主题 | 本目录采用的表达 |
| --- | --- |
| 项目定位 | 经纪商自有CPA合作者体系；不是开放多广告主平台 |
| 中文名称 | 人员及业务主体统一称“合作者”；既有文件名和技术字段可保留历史名称 |
| CRM | 账户、资料、认证、KYC/KYB及相关客户、资金与交易事实源；Affiliate保存引用、同步结果及审计 |
| 数据连接 | 可受控直连CRM数据库；读写表/视图、权限、版本和新鲜度仍需评审，不假设任意跨库改写 |
| 归因 | CRM补齐注册归因资料；Affiliate负责最终归因结论，IB与CPA身份及客户归属隔离 |
| 计佣 | FTD是里程碑；基础FTD段与有效FTD段合计100%；质量服务额外计奖并独立案件 |
| 资金 | 每日自动结算进入可提现余额；自然月生成月度结算单；提现引用可提现明细；审批后请求CRM实际打款 |
| 风险 | 集群、调查、隔离和关键缺数阻断自动结算，不阻断佣金计算 |
| 冻结对象 | 超时冻结按当前客户、当前佣金、当前结算案件三元组；其他案件不连带 |
| 风险与信用 | R0–R3和C0–C4分开保存、计算和审计 |
| 审批 | 按[权限契约§5.2](../契约/14-角色权限与审批契约-v1.0.md)，提交时配置允许、具备当前对象动作权限并显式选择，可同事务记录SUBMIT及APPROVE且self_review=true；未选不得事后自审，其他必要专业节点仍须完成。08/09已同步，其他旧图与具体权限配置继续沿SBV-22核验 |
| IMC | 消费数据做分析，不参与计佣，不作为计佣前置回流 |
| 币种与参数 | MVP仅USD；未签核阈值、SLA、保留期及比例不写成生产默认值 |
